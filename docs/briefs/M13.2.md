## Goal

Finish the `find_free_times` side of meeting times (SPEC §11.8, §21.2,
§21.3, §21.4, §21.5, §21.8, §21.9 "`FreeTimeFinder`"). `FreeTimeFinder`
builds an `OwnerCalendar` from the owner's free/busy string it already
fetches (no extra Outlook call), ranks the whole free blocks with
`MeetingRanking.Rank` before taking `max_suggestions`, adds `adjacent` to
each suggestion, and builds exact-length offers with
`MeetingOffers.Build` (CET part and European office-hours split only when
the new `offer_cet` argument is true), returned as `offers` and
`offer_text`. `IFreeBusySource` methods get a `WorkPriority` parameter so
M13.4 can read free/busy at `Background` priority; `OutlookFreeBusySource`
passes it through to `OutlookWorker.RunAsync`. The MCP tool gets the
`offer_cet` argument and the new description. **Reuse the M13.1
primitives; write no second ranking, candidate, selection, line-format or
heading routine.**

## Public API

### `IFreeBusySource` (`FreeTimeFinder.cs`)

```csharp
public interface IFreeBusySource
{
    /// <summary>The signed-in user (own mailbox owner). Email is a primary SMTP address.</summary>
    Task<Recipient> GetCurrentUserAsync(WorkPriority priority, CancellationToken ct);

    /// <summary>Joined free/busy string starting at from.Date. Null = unknown attendee.</summary>
    Task<string?> GetFreeBusyAsync(string email, DateTime from, DateTime to, int intervalMinutes,
        WorkPriority priority, CancellationToken ct);
}
```

`priority` comes right before `ct`, without a default, like
`IAiMailbox.GetFactsAsync` / `GetIdentityAsync`. The PLAN's "default
`Interactive`" is met by the callers: `FreeTimeFinder` (the MCP path)
always passes `WorkPriority.Interactive`; M13.4 passes the drafting
path's priority. (A C# default can't sit before a required `ct`, and a
second overload would just be more surface for every fake.)

### `OutlookFreeBusySource` (App)

```csharp
internal sealed class OutlookFreeBusySource(OutlookWorker worker) : IFreeBusySource
{
    public Task<Recipient> GetCurrentUserAsync(WorkPriority priority, CancellationToken ct) =>
        worker.RunAsync(app => OutlookCalendar.GetCurrentUser(app), priority, ct);

    public Task<string?> GetFreeBusyAsync(string email, DateTime from, DateTime to, int intervalMinutes,
        WorkPriority priority, CancellationToken ct) =>
        worker.RunAsync(app => OutlookCalendar.GetFreeBusy(app, email, from, to, intervalMinutes), priority, ct);
}
```

Exceptions are whatever `OutlookWorker.RunAsync` throws today
(`OutlookUnavailableException`, `OutlookNotRespondingException`, …),
unchanged.

### `McpTools.FindFreeTimes` (App)

```csharp
public Task<FreeTimesResult> FindFreeTimes(
    FreeTimeFinder finder,
    Settings settings,
    [Description("Attendees as \"Name <email>; Name <email>\". Split on \";\" only.")] string recipients,
    [Description("Meeting length in minutes, 1-1440: the minimum length of a suggestion and the exact length of each offer.")] int duration_minutes = 60,
    [Description("Calendar days to search, starting with date_from's day (max 60).")] int days_ahead = 10,
    [Description("Start date or date-time, local time (ISO). Default: now.")] string? date_from = null,
    [Description("Working-hours window, 0-23. Default: tray settings.")] int? earliest_hour = null,
    [Description("Working-hours window, 1-24. Default: tray settings.")] int? latest_hour = null,
    [Description("Skip Saturdays and Sundays. Default: tray settings.")] bool? business_days_only = null,
    [Description("Also check the calendar owner (you, or the shared mailbox). Needed for the ranking next to the owner's meetings.")] bool include_me = true,
    [Description("1-20. The number of suggestions, and of offers in total.")] int max_suggestions = 5,
    [Description("Empty = your calendar; or the SMTP address of an enabled shared mailbox.")] string? mailbox = null,
    [Description("Set to true when the person you are writing to is in Europe: each offer also shows the time in CET, and options between 08:00 and 18:00 CET come first, with the others in a second list headed \"Outside European office hours:\".")] bool offer_cet = false,
    CancellationToken cancellationToken = default)
    => finder.FindAsync(new FreeTimeRequest(recipients, duration_minutes, days_ahead, date_from,
           earliest_hour, latest_hour, business_days_only, include_me, max_suggestions, mailbox, offer_cet),
           settings, cancellationToken);
```

`FindFreeTimesDescription`, exact text (one C# string constant):

```
Finds meeting times when everyone is free, from Outlook free/busy. Paste recipients as "Last, First <email>; ..." (separate with ";"). Returns "suggestions": whole free blocks, numbered, with start/end (local time, ISO with offset), ranked so that times right before or after the calendar owner's meetings come first, then times next to tentative meetings, then the rest, each group in date order ("adjacent" says which), plus a ready-to-show "text". Also returns "offers": up to max_suggestions options of exactly duration_minutes, in the same ranking, and "offer_text" with one option per line. When proposing times in an email, paste offer_text as is, without reordering or retyping the times, and set offer_cet=true when the person you are writing to is in Europe. People whose free/busy can't be read (e.g. outside the organization) are listed in unknown_attendees and ignored. Nothing is booked. To book a suggestion or offer, pass its start and end to send_meeting_invite.
```

## Behavior

`FindAsync` keeps steps 1–8 exactly as now (parsing, validation, clamps,
`now`, range, mailbox, empty check, owner). Changes:

1. **Owner email.** When `IncludeMe` is true, remember the owner's email
   (the current user from `source.GetCurrentUserAsync(WorkPriority.Interactive, ct)`,
   or the shared mailbox SMTP) as `ownerEmail`, also when the owner was
   already listed among the recipients (the existing dedupe stays). When
   `IncludeMe` is false there is no owner: `owner = OwnerCalendar.Unknown`,
   even if the user's own address is in `recipients` (§11.8 "With
   `include_me=false` … every block and offer is `none`").
2. **Free/busy loop.** Calls become
   `source.GetFreeBusyAsync(a.Email, from, to, interval, WorkPriority.Interactive, ct)`.
   Known/unknown classification is unchanged. For the attendee whose email
   equals `ownerEmail` (`OrdinalIgnoreCase`) **and** who ends up in
   `known`, set `owner = OwnerCalendar.FromFreeBusy(fb, from.Date, interval)`.
   Otherwise (owner null, empty, short or invalid) `owner` stays
   `OwnerCalendar.Unknown`. No extra Outlook call.
3. **Blocks.** `blocks = known.Count == 0 ? [] : FreeBusy.FreeSlots(busyLists, from, to, startHour, endHour, businessDays, duration, now, interval)`
   as now, but keep the **full** list (no `OrderBy`/`Take` here).
4. **Suggestions.** `MeetingRanking.Rank(blocks, owner).Take(max)`. In
   that order, number from 1: `label = SlotFormatter.Format(i + 1, …)`
   exactly as now, `Start`/`End` with the existing `Iso` helper,
   `Adjacent = MeetingRanking.Name(rr.Tier)`. `text` is unchanged: the
   labels joined with `\n`, or the two existing "no …" messages.
5. **Offers.** When `blocks` is empty, `offers = []` and
   `offerText = ""` (do not call `Build`, and do not call `centralEurope`).
   Otherwise:
   ```csharp
   var cet = request.OfferCet ? (centralEurope ?? SenderRegion.CentralEurope)() : null;
   var set = MeetingOffers.Build(blocks, owner, duration, max, timeZone, settings.TimeZoneLabel,
       europe: request.OfferCet, centralEurope: cet);
   ```
   `centralEurope` is invoked only when `OfferCet` is true. Each
   `MeetingOffer o` in `set.All` becomes
   `new FreeTimeOffer(o.N, o.Line, Iso(o.Range.Start), Iso(o.Range.End), MeetingRanking.Name(o.Tier), o.ListName)`.
   `offerText = set.ToText()` (no argument: the default English heading,
   §21.8). This gives, by M13.1: candidates at 30-minute steps plus the
   end-aligned one, selection by tier then start without overlaps, at most
   `max` options in total, no CET part and no split when `offer_cet` is
   false, when the owner's zone already has the CET offset, or when the
   CET zone is missing.
6. **CET missing.** When `set.CetMissing` is true, log
   `CetMissingWarning` at Warning level, **once per `FreeTimeFinder`
   instance** (an `int` flag set with `Interlocked.Exchange`; the app has
   one singleton). Nothing else is logged by this class.
7. **Result.** `new FreeTimesResult(suggestions, text, offers, offerText, unknown, attendees)`.

Edge cases:
- No known attendee → `suggestions = []`, `offers = []`, `offer_text = ""`,
  `text` = the existing "No free/busy information …" message.
- Known attendees but no block → `offers = []`, `offer_text = ""`, `text`
  = the existing "No free time of at least …" message.
- Owner unknown (not in the source map, short, invalid) with other
  attendees known → everything `none`, date order (same as before M13).
- `TentativeIsBusy = false`: free blocks may contain the owner's
  tentative time; a block that overlaps a tentative run is not adjacent to
  it (§21.2, overlap doesn't count). Nothing special to code: the
  primitives do it.
- Offers use the same `now` cut-off as the blocks and no extra lead time
  (§11.8 Details).
- `duration_minutes` up to 1440 is fine: `Build` simply finds no
  candidates.
