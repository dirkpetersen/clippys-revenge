# M19.3 OneDrive/SharePoint mapping in Core: `SyncedRoot`, `OneDriveScopes`, `OneDriveLinks`, `OneDriveMap`, `SyncedFileReader`

Base: `dev`. No deps. Pure Core, runs beside M19.2 (extractors), M17.1 and
M18.1; see "Parallel work" for the disjoint file sets.

## Goal

The Core half of "shared files, synced only" (§26.3). Find OneDrive/
SharePoint links in an email body (`OneDriveLinks.Find`: URL scan, trailing
punctuation, Safe Links unwrap, the pinned Microsoft host rule
`OneDriveLinks.IsMicrosoftFileHost`, `Text <url>` names, 10 per body),
map a link to the **local copy the OneDrive sync client keeps**
(`OneDriveMap.Map`: decode, `/:x:/r/` → direct, token links /
`_layouts` / `1drv.ms` / `onedrive.live.com` unmappable, longest
segment-boundary prefix, `FileNames.SafeFileName` segments), and read that
file (`SyncedFileReader`: `PathPolicy` with the mount as the only root,
`FileShare.ReadWrite | Delete`, size from metadata, placeholders allowed).
The registry layout of §26.3 "Sync data" is turned into `SyncedRoot`s in
Core (`OneDriveScopes.Build`) behind `IOneDriveRegistryData`, so all of it
is tested on Linux with fake registry data; M19.7 only supplies the HKCU
reads. Nothing here makes a network request (no Graph, no OAuth, no HTTP),
and nothing logs a URL, name, path or text.

SPEC refs: §26.3 (all), §26.1 (links bullet, kinds), §26.11 (rules these
files must already satisfy), §26.12 (`OneDriveLinks.Find`, host rule and
`OneDriveMap.Map` bullets), §12 (`PathPolicy`, `FileNames`), §1 rules 6
and 8, §2, §3.

## Hard rules that apply here

- **No Graph, no OAuth, no network.** No `HttpClient`, `WebRequest`,
  `WebClient`, `Socket`, `Dns`, `Process`, `UseShellExecute` in these files.
  A link is only ever turned into a local path and read from disk.
- **Every path through `PathPolicy`.** `SyncedFileReader` calls
  `PathPolicy.Check(path, [root.MountPoint], PathMode.Read)` before it
  touches the file; the mount is the only allowed root.
- **Microsoft hosts only** (the user's decision of 2026-11-15). A URL on
  any other host is never mapped, never opened, gives no item and no log.
  A synced scope whose prefix host fails the rule is ignored, so a mapping
  can only ever land under a Microsoft root.
- **No registry in Core.** `Microsoft.Win32.Registry` is not referenced;
  Core sees only `IOneDriveRegistryData` (M19.7 implements it in App).
- **Nothing logged but literals, counts and type names** (§26.11). Only
  `OneDriveScopes.Build` logs, once, Warning, exception type only.
- No reference to `EmailIndex`/`MailboxIndexes` from these files.
- No new package.

```csharp
namespace ClippysRevenge.Core;

// ---------------------------------------------------------------- OneDriveScopes.cs

/// <summary>Raw string values of one subkey of HKCU\Software\SyncEngines\Providers\OneDrive (SPEC 26.3).
/// App passes `key.GetValue(name)?.ToString()`; Core validates.</summary>
public sealed record OneDriveScopeValues(string? MountPoint, string? UrlNamespace, string? LibraryType,
    string? IsFolderScope, string? FullRemotePath);

/// <summary>HKCU\Software\Microsoft\OneDrive\Accounts\Personal values UserFolder and cid (consumer fallback).</summary>
public sealed record OneDrivePersonalValues(string? UserFolder, string? Cid);

/// <summary>The registry reads of SPEC 26.3, implemented in App (M19.7, OneDriveRegistry.cs). Read-only.
/// Members may throw; Build turns that into an empty list.</summary>
public interface IOneDriveRegistryData
{
    IReadOnlyList<OneDriveScopeValues> ReadScopes();
    OneDrivePersonalValues? ReadPersonal();       // null when the key or a value is missing
}

public static class OneDriveScopes
{
    /// <summary>SPEC 26.3 "Sync data". Never throws: any exception from `data` → empty list and one
    /// Warning "OneDrive sync scopes could not be read ({ErrorType})" with the exception type name only.
    /// directoryExists defaults to Directory.Exists (tests inject a fake).</summary>
    public static IReadOnlyList<SyncedRoot> Build(IOneDriveRegistryData data, ILogger? logger = null,
        Func<string, bool>? directoryExists = null);
}

// ---------------------------------------------------------------- OneDriveMap.cs

/// <summary>SPEC 26.3. UrlPrefix is an absolute https URL ending in "/"; MountPoint a local folder.</summary>
public sealed record SyncedRoot(string UrlPrefix, string MountPoint, string LibraryType, bool IsFolderScope);

public abstract record MappedLink
{
    private MappedLink() { }
    /// <summary>Path is MountPoint + the remaining segments; Root is the matched scope (its MountPoint is the
    /// only PathPolicy root for this path). PathPolicy has NOT run yet.</summary>
    public sealed record Local(string Path, SyncedRoot Root) : MappedLink;
    public sealed record Unmappable(string Reason) : MappedLink;
}

public static class OneDriveMap
{
    /// <summary>Same text as AttachmentReasons.NotSynced (M19.2); M19.4 makes this point at it.</summary>
    public const string NotSyncedReason = "not synced to this PC";

    /// <summary>SPEC 26.3 "Mapping" steps 1-4. Pure, never throws (null/garbage → Unmappable).
    /// Every Unmappable has Reason NotSyncedReason.</summary>
    public static MappedLink Map(string? url, IReadOnlyList<SyncedRoot>? roots);

    /// <summary>Steps 1-2 for an already parsed https URL on a Microsoft host: the decoded path segments of a
    /// direct path (share-link "/:x:/r/" prefix removed), or null when unmappable (token link, _layouts,
    /// onedrive.live.com, 1drv.ms, '\', control char, "."/".." segment). Shared by Map and OneDriveLinks.</summary>
    internal static string[]? DirectSegments(Uri uri);
}

public abstract record SyncedFileResult
{
    private SyncedFileResult() { }
    public sealed record Bytes(byte[] Data, string FileName) : SyncedFileResult;   // FileName = Path.GetFileName(full)
    public sealed record NotSynced : SyncedFileResult;                             // missing, folder, refused path
    public sealed record TooLarge(long Length) : SyncedFileResult;
    public sealed record Failed(string ErrorType) : SyncedFileResult;              // exception type name only
}

public static class SyncedFileReader
{
    /// <summary>SPEC 26.3 steps 5 and "Reading a synced file". Synchronous (the caller runs it on the thread
    /// pool with its timeout, M19.4). Throws only OperationCanceledException (ct) and ArgumentNullException.</summary>
    public static SyncedFileResult Read(MappedLink.Local link, long maxBytes, CancellationToken ct);
}

// ---------------------------------------------------------------- OneDriveLinks.cs

/// <summary>A kept link. Url: the (Safe Links-unwrapped) URL, Uri.AbsoluteUri. NormalizedUrl: the dedupe key.
/// Name: the display name of SPEC 26.3.</summary>
public sealed record FoundLink(string Url, string NormalizedUrl, string Name);

public static class OneDriveLinks
{
    public const int MaxPerBody = 10;
    public const int MaxNameChars = 120;

    /// <summary>SPEC 26.3 "Finding links". Body order, deduped by NormalizedUrl, at most MaxPerBody (counted
    /// after the host filter). Null/empty → empty. Never throws.</summary>
    public static IReadOnlyList<FoundLink> Find(string? body);

    /// <summary>One URL (a cloud attachment's): trim, Safe Links unwrap, host rule. False when it fails
    /// (M19.4 then uses reason "not a OneDrive or SharePoint link"). Name uses the direct-path or host
    /// fallback rule (no surrounding text). Never throws.</summary>
    public static bool TryParse(string? url, [NotNullWhen(true)] out FoundLink? link);

    /// <summary>SPEC 26.3 "Host rule". Null → ArgumentNullException; relative URI → false.</summary>
    public static bool IsMicrosoftFileHost(Uri uri);

    /// <summary>IdnHost, lower-case invariant, one trailing '.' removed.</summary>
    internal static string NormalizedHost(Uri uri);
}
```

## Behavior

### A. Host rule (`IsMicrosoftFileHost`)

True only when all hold:
- `uri.IsAbsoluteUri`, `uri.Scheme == "https"`;
- `uri.UserInfo` is empty;
- `uri.IsDefaultPort` (an explicit `:443` is fine; `:8443` is not);
- `uri.HostNameType == UriHostNameType.Dns` (IP literals refused);
- `h = NormalizedHost(uri)` is exactly `onedrive.live.com`,
  `d.docs.live.net` or `1drv.ms`, or ends with `.sharepoint.com` and is
  longer than `.sharepoint.com` (at least one label before it; bare
  `sharepoint.com` refused).

Nothing else: not `.sharepoint.us/.de/.cn`, `*.sharepoint-df.com`,
`*.office.com`, `*.live.com` (other than the two above), and not a host
just because a synced scope uses it.

### B. Safe Links unwrap (`UnwrapSafeLinks`, internal, used by `Find` and `TryParse`)

- When `NormalizedHost(uri)` ends with `.safelinks.protection.outlook.com`:
  split `uri.Query` (without `?`) on `&`; the first pair whose name is
  `url` (OrdinalIgnoreCase); value `Uri.UnescapeDataString` once (no `+`
  → space); `Uri.TryCreate(value, UriKind.Absolute)` with scheme `https`,
  else the link is **dropped**. The result is not unwrapped again (a
  wrapper in a wrapper fails the host rule and is dropped).
- Any other host: the URL itself.
- Then the host rule (A) on the result; failing → dropped.

### C. `Find(body)`

1. Scan for `https://` (OrdinalIgnoreCase). The candidate runs to the
   first whitespace, `<`, `>` or `"` (or the end). Then repeatedly trim
   trailing characters from `.,;:!?)]`. Next scan starts after the
   candidate.
2. `Uri.TryCreate(candidate, UriKind.Absolute)`; failure → skip.
3. Unwrap (B) and host rule; dropped → skip silently (no item, nothing
   recorded).
4. `NormalizedUrl` = `"https://" + NormalizedHost(u) + u.GetComponents(UriComponents.PathAndQuery, UriFormat.UriEscaped)`
   (fragment dropped, query kept, path case kept). Already seen →
   skip.
5. `Name`:
   - when the host ends with `.sharepoint.com` or is `d.docs.live.net`
     and `OneDriveMap.DirectSegments(u)` is non-null with at least one
     segment: its last segment (already decoded);
   - else, when the character right before the candidate in the body is
     `<` (Outlook's plain-text `Text <https://…>`): the text between the
     last `\n` or `>` before that `<` (or the body start) and the `<`,
     trimmed; longer than `MaxNameChars` → its last `MaxNameChars`
     characters, `TrimStart()`; empty → next rule;
   - else `a shared file on <NormalizedHost>` (the inner host for an
     unwrapped Safe Link).
6. Add; stop when `MaxPerBody` links are kept.

`TryParse(url)`: `url?.Trim()`, then 2–5 without the `Text <url>` rule;
`false` when anything fails.

### D. `OneDriveMap.DirectSegments(uri)` (steps 1–2 of §26.3 "Mapping")

1. Host `onedrive.live.com` or `1drv.ms` → null (ids, not paths).
2. `path = Uri.UnescapeDataString(uri.AbsolutePath)` (query and fragment
   dropped). Contains `\` or any `char.IsControl` → null. Split on `/`,
   empty segments removed. Any segment `.` or `..` → null.
3. Any segment equal to `_layouts` (OrdinalIgnoreCase) → null.
4. First segment matching `^:[a-z]{1,2}:$` (case-insensitive): when a
   second segment exists and equals `r` (OrdinalIgnoreCase), drop both;
   otherwise (`s`, `g`, `p`, `t`, … opaque tokens, or nothing) → null.
5. Return the remaining segments (may be empty).

### E. `OneDriveMap.Map(url, roots)`

1. `url` null/blank, `roots` null, `Uri.TryCreate` fails or
   `!IsMicrosoftFileHost(uri)` → `Unmappable`. (No Safe Links unwrap
   here: callers pass `FoundLink.Url`, already unwrapped.)
2. `segs = DirectSegments(uri)`; null → `Unmappable`.
3. For every root: skip the root when its `UrlPrefix` doesn't parse as an
   absolute URI that passes `IsMicrosoftFileHost`, its `MountPoint` is
   blank, or its decoded path (same decoding as D.2, split on `/`,
   empties removed) has a `.`/`..` segment, `\` or a control character.
   It matches when `NormalizedHost` equals the URL's and its segments are
   a prefix of `segs`, each compared OrdinalIgnoreCase (so
   `/Shared Documents2` is not under `/Shared Documents`). The root with
   the most segments wins; on a tie the first in `roots` order.
4. No match, or no segments left after the prefix (the URL is the root
   folder itself) → `Unmappable`.
5. Every remaining segment must satisfy `FileNames.SafeFileName(s) == s`
   (Ordinal); else `Unmappable`.
6. `Path = Path.Join(mount.TrimEnd('\\', '/'), s1, s2, …)` built with
   `Path.DirectorySeparatorChar` (`\` on Windows). `Local(Path, root)`.

Every `Unmappable` carries `NotSyncedReason`.

### F. `SyncedFileReader.Read(link, maxBytes, ct)`

1. `ct.ThrowIfCancellationRequested()`.
2. `full = PathPolicy.Check(link.Path, [link.Root.MountPoint], PathMode.Read)`.
   `PathNotAllowedException`, `FileNotFoundException`
   (missing or a folder), `ArgumentException` → `NotSynced`.
   `UnauthorizedAccessException`/`IOException` → `Failed(type name)`.
   A Files-On-Demand placeholder is not a link (`LinkTarget` is null for
   cloud reparse points) and passes.
3. `len = new FileInfo(full).Length` (full logical size, also for a
   placeholder; nothing is opened yet). `len > maxBytes` → `TooLarge(len)`.
4. `new FileStream(full, FileMode.Open, FileAccess.Read, FileShare.ReadWrite | FileShare.Delete, 81_920, FileOptions.SequentialScan)`;
   read in chunks of 81,920 bytes into a buffer pre-sized to `len`,
   growing if the file grew, `ct.ThrowIfCancellationRequested()` before
   each chunk, until EOF or more than `maxBytes` bytes were read
   (→ `TooLarge(<bytes read>)`). The stream is disposed at once. The
   result array is exactly the bytes read. No copy of the file is made on
   disk.
5. `FileNotFoundException`/`DirectoryNotFoundException` at open (a race)
   → `NotSynced`; other `IOException`/`UnauthorizedAccessException` →
   `Failed(type name)`. `OperationCanceledException` propagates.
6. `Bytes(data, Path.GetFileName(full))`.

No logging here. Opening a placeholder may make the OneDrive client
download it; that is the user's sync client (§26.3 Files-On-Demand), not
a network call by Clippy. The time it takes counts against M19.4's limits.

### G. `OneDriveScopes.Build(data, logger, directoryExists)`

1. `scopes = data.ReadScopes()`, `personal = data.ReadPersonal()` inside
   one `try`; any exception → log Warning
   `"OneDrive sync scopes could not be read ({ErrorType})"` with
   `e.GetType().Name`, return `[]`.
2. For each `OneDriveScopeValues` in order:
   - `folder = IsFolderScope?.Trim() == "1"`;
   - prefix = `FullRemotePath` when `folder` and non-blank, else
     `UrlNamespace`; trimmed; `/` appended when missing;
   - the prefix must parse as an absolute URI with scheme `https` that
     passes `OneDriveLinks.IsMicrosoftFileHost`; else skip;
   - mount = `MountPoint` trimmed; must match `^[A-Za-z]:\\` (a drive
     path; UNC, `\\?\` and relative paths fail), contain no control
     character and no `.`/`..` segment, and `directoryExists(mount)`
     must be true; else skip;
   - `new SyncedRoot(prefix, mount, LibraryType?.Trim() ?? "", folder)`.
3. Consumer fallback: when `personal` has non-blank `UserFolder` and a
   `Cid` matching `^[0-9A-Za-z]{1,32}$`, and **no** root from step 2 has a
   prefix starting with `https://d.docs.live.net/` (OrdinalIgnoreCase):
   add `SyncedRoot($"https://d.docs.live.net/{cid}/", userFolder, "personal", false)`
   after the same mount checks.
4. Collapse duplicates: same `UrlPrefix` and same `MountPoint`, both
   OrdinalIgnoreCase; the first stays.
5. `directoryExists` exceptions count as `false`. Never throws.

Not used: `WebUrl`, `GraphDriveId`, `CID` of the SyncEngines keys, and the
`%LOCALAPPDATA%\Microsoft\OneDrive\settings\…` files.

## Spec changes

Not applied by this brief (the caller asked for the brief only); to be
recorded in `SPEC.md`:

1. **§26.3 Sync data / §3 layout**: the validation of §26.3 "Sync data"
   (prefix choice, https + host rule, drive-letter mount that exists,
   duplicates, consumer fallback) is Core:
   `OneDriveScopes.Build(IOneDriveRegistryData, ILogger?, Func<string,bool>?)`
   over `OneDriveScopeValues`/`OneDrivePersonalValues` (raw strings). App's
   `OneDriveRegistry.Read()` (M19.7) only implements
   `IOneDriveRegistryData` with the HKCU reads and calls `Build`. Files:
   `OneDriveLinks.cs` (`FoundLink`, `OneDriveLinks`), `OneDriveMap.cs`
   (`SyncedRoot`, `MappedLink`, `OneDriveMap`, `SyncedFileResult`,
   `SyncedFileReader`), `OneDriveScopes.cs`; all match the §26.11
   `OneDrive*.cs` scan.
2. **§26.3 consumer fallback**: added only when no SyncEngines scope has a
   `https://d.docs.live.net/` prefix; `cid` must be 1–32 letters/digits.
   A mount point must be a drive path (`X:\…`) with no `.`/`..` segment.
3. **§26.3 Mapping API**: `MappedLink.Local(string Path, SyncedRoot Root)`
   (the root is carried so the reader can run `PathPolicy` with that
   mount). `Map` doesn't unwrap Safe Links (callers pass the unwrapped
   `FoundLink.Url`). A URL equal to a root folder is unmappable. Ties
   between equally long prefixes go to the first root. Segments are
   joined with `Path.DirectorySeparatorChar` (`\` on Windows).
4. **§26.3 normalized URL** (dedupe key): `https://` + lower-case IDN
   host without trailing dot + escaped path and query; fragment dropped.
5. **§26.3 link names**: `Text <url>` text is taken from the last line
   break or `>` before the `<`; when longer than 120 characters its last
   120 are kept. `OneDriveLinks.TryParse` handles one URL (cloud
   attachments) with the same unwrap and host rule.
6. **§26.3 reading a synced file**: `SyncedFileReader.Read(MappedLink.Local, long maxBytes, CancellationToken)`
   is synchronous (M19.4 runs it on the thread pool with its timeout) and
   returns `Bytes`/`NotSynced`/`TooLarge`/`Failed(type)`: missing file,
   folder or `PathPolicy` refusal → `NotSynced` (reason
   `not synced to this PC`); a file that grows past the cap while being
   read → `TooLarge`.
