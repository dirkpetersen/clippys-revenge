# M1.4 `HtmlBody` + tests

## Goal

Add `HtmlBody` to Core: a pure, static helper that turns plain text into
escaped HTML and inserts an HTML fragment at the top of an existing HTML
body (SPEC §12 "`HtmlBody.FromPlainText` / `HtmlBody.InsertAtTop`", §3
layout row `HtmlBody.cs`). The App's draft code (SPEC §8 "Draft bodies",
§11.5 `create_draft`, §11.6 `reply_draft`) will call it later; this task
only builds and tests the helper (§15 `HtmlBody` row: escaping, paragraphs
and line breaks, insert after `<BODY class=…>`, no body tag). No COM, no
Windows, runs on Linux.

## Cross-task dependencies

None. Uses only the BCL (`System.Text`, `System.Text.RegularExpressions`).
Requires the M0.1 projects to exist (Core csproj, test csproj with xunit v3
and the global `using Xunit;`).

## Spec changes (proposed)

Replace the `HtmlBody` paragraph in SPEC §12 (currently lines starting
"- `HtmlBody.FromPlainText(string)`: HTML-encodes the text; …") with:

```
- `HtmlBody.FromPlainText(string)`: normalizes `\r\n` and `\r` to `\n`,
  then encodes exactly `&` `<` `>` `"` `'` (as `&amp;` `&lt;` `&gt;`
  `&quot;` `&#39;`); other characters, including non-ASCII, pass through.
  One or more blank (empty or whitespace-only) lines separate paragraphs;
  each paragraph becomes `<p>…</p>` and single newlines inside it become
  `<br>`. Leading and trailing blank lines are dropped, the output has no
  whitespace between tags, and text that is empty or all blank gives `""`.
  URLs stay plain text (no `<a>`). Spaces and tabs are not converted to
  `&nbsp;`.
  `HtmlBody.InsertAtTop(string html, string fragment)`: inserts the
  fragment right after the first opening `<body…>` tag (case-insensitive,
  attributes allowed, including quoted values that contain `>`; `<tbody>`
  and `<bodyx>` don't count), or prepends it when there is no complete body
  tag. Nothing else in `html` changes.
```

These are low-risk, reversible refinements that pin down what the spec
leaves open. They don't change security or a hard rule.

## Public API

```csharp
namespace ClippysRevenge.Core;

public static partial class HtmlBody
{
    /// Plain text -> escaped HTML paragraphs. Throws ArgumentNullException if text is null.
    public static string FromPlainText(string text);

    /// Inserts fragment right after the first opening <body…> tag, or prepends it.
    /// Throws ArgumentNullException if html or fragment is null.
    public static string InsertAtTop(string html, string fragment);
}
```

`partial` only so a `[GeneratedRegex]` private member can be used. Any
private helpers are fine. No other public members.

## Behavior

### `FromPlainText(string text)`

1. `ArgumentNullException.ThrowIfNull(text)`.
2. Replace `"\r\n"` with `"\n"`, then any remaining `"\r"` with `"\n"`.
3. Split into lines on `'\n'`. A line is **blank** when
   `string.IsNullOrWhiteSpace(line)`.
4. Group consecutive non-blank lines into paragraphs. Any run of one or
   more blank lines ends a paragraph. Leading and trailing blank lines
   produce nothing (no empty `<p></p>` anywhere).
5. Each paragraph is `"<p>" + string.Join("<br>", encodedLines) + "</p>"`.
   The paragraphs are concatenated with no separator. No trailing newline.
6. Encoding, per line, exactly these five characters and nothing else:
   `&` → `&amp;`, `<` → `&lt;`, `>` → `&gt;`, `"` → `&quot;`, `'` → `&#39;`.
   Do **not** use `WebUtility.HtmlEncode` or `HttpUtility.HtmlEncode`:
   they also turn Latin-1 and surrogate pairs into numeric entities, which
   bloats the body and breaks the exact expectations below. Non-ASCII
   (`ü`, emoji) passes through unchanged. Text that already looks like an
   entity is encoded again (`&amp;` → `&amp;amp;`).
7. Inside a non-blank line, keep the characters as they are, including
   leading and trailing spaces and tabs (encoded only per rule 6). No
   `&nbsp;` conversion and no trimming.
8. URLs are not linkified. `https://x/?a=1&b=2` becomes
   `https://x/?a=1&amp;b=2`, with no `<a` in the output.
9. If no paragraph is produced (empty input or only blank lines), return
   `""`.

### `InsertAtTop(string html, string fragment)`

1. `ArgumentNullException.ThrowIfNull(html)` and
   `ArgumentNullException.ThrowIfNull(fragment)`.
2. If `fragment` is empty, return `html` unchanged (same content).
3. Find the **first** match of this regex, with
   `RegexOptions.IgnoreCase | RegexOptions.CultureInvariant`, as a
   `[GeneratedRegex]`:

   ```
   <body(?=[\s/>])(?:[^>"']|"[^"]*"|'[^']*')*>
   ```

   - The lookahead means `<tbody>`, `<bodyguard>` and `<body-x>` are not
     body tags (`<tbody` doesn't start with `<body` anyway).
   - Attribute values in double or single quotes may contain `>`
     (`<body style='a>b'>`), and the match runs to the real end of the tag.
   - Whitespace in the tag, including newlines, is allowed
     (`<body\r\nlang=EN-US>`).
   - The alternatives start with disjoint characters, so there is no
     catastrophic backtracking. No match timeout is needed.
4. On a match, return
   `html[..(m.Index + m.Length)] + fragment + html[(m.Index + m.Length)..]`.
   Only the first body tag is used. A later `<body>` (for example inside
   quoted content) is left alone.
5. With no match (no body tag, or an unterminated `<body …` with no `>`),
   return `fragment + html`. If `html` is empty, that is just `fragment`.
6. Insert no extra whitespace, wrapper, or separator. Spacing between the
   new text, the signature and the quoted original is the App's job (§8),
   not this helper's.

## Tests

`tests/ClippysRevenge.Core.Tests/HtmlBodyTests.cs`, class `HtmlBodyTests`.
These are cross-platform, so no traits. Use `[Theory]`/`[InlineData]`
where it reads well. In C# literals below, `\n`/`\r`/`\t` are escape
sequences.

### `FromPlainText`

| # | Input | Expected |
|---|---|---|
| 1 | `a < b & "c" 'd' > e` | `<p>a &lt; b &amp; &quot;c&quot; &#39;d&#39; &gt; e</p>` |
| 2 | `"Hi Bob,\n\nThanks.\nSee you"` | `<p>Hi Bob,</p><p>Thanks.<br>See you</p>` |
| 3 | `"a\r\nb\r\n\r\nc"` | `<p>a<br>b</p><p>c</p>` |
| 4 | `"a\rb"` | `<p>a<br>b</p>` |
| 5 | `"a\n\n\n\nb"` | `<p>a</p><p>b</p>` |
| 6 | `"a\n  \t\nb"` (whitespace-only line) | `<p>a</p><p>b</p>` |
| 7 | `"\n\na\n\n"` | `<p>a</p>` |
| 8 | `""` | `""` |
| 9 | `"\n \r\n\t"` | `""` |
| 10 | `"See https://x.com/?a=1&b=<2>"` | `<p>See https://x.com/?a=1&amp;b=&lt;2&gt;</p>`; also `Assert.DoesNotContain("<a", result)` |
| 11 | `"Grüße 😀"` | `<p>Grüße 😀</p>` |
| 12 | `"&amp;"` | `<p>&amp;amp;</p>` |
| 13 | `"a  b\t c "` | `<p>a  b\t c </p>` (spaces/tab kept) |
| 14 | `"line"` | `<p>line</p>` |
| 15 | `null!` | throws `ArgumentNullException` |
