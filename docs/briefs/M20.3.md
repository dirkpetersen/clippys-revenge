# M20.3 "Don't draft for this sender" tray items

Base: `dev` with M16.7 merged (the AI drafts submenu has the rescan item,
`AiDraftsMenuModel` has the rescan fields). Independent of M17–M19 and
M20.1/M20.2. **No release for this task** (the user, 2026-11-15:
everything ships later as v0.1.1); do not bump `<Version>`.

## Goal

Two new items in the tray's **AI drafts** submenu, right after *Draft a
reply to the selected email*: *Don't draft for this sender* and *Don't
draft for this sender's domain…* (§27.7, §6.2). Each takes the email
selected in Outlook, works out the sender's address or domain, refuses the
user's own address/organization, skips what `ExcludeSenders` already
covers and the 200-entry limit, asks for confirmation for a domain, and
appends the entry to `AiDrafting.ExcludeSenders` through the normal
settings path (clone, change, `Validate()`, save, AI-settings-changed
notification). Feedback is a click-feedback balloon plus one `Ai` event
that carries no address. Both items are disabled while a rescan runs.
All decisions and texts live in Core (tested); App only has the menu
items and the dialog.

SPEC refs: §27.7 (all of it), §6.2 (menu layout), §19.2 (`ExcludeSenders`,
200 entries, domain rule), §19.7 (manual path: selection and its
balloons), §6.3 (the Settings window and tray changes), §6.5
(click-feedback balloons).

## Hard rules that apply here

- **Never send, never delete, never move.** This task changes only
  settings. Existing drafts for that sender are not touched (§27.7). No
  new COM code: the selection is read through the existing
  `IAiMailbox.GetSelectedAsync`/`ReadEmailAsync` (Interactive).
- **No address in Activity or logs** (§27.7, §19.11). The address or
  domain appears only in the balloon and the confirmation dialog (both
  shown to the user). Log lines carry the kind (`address`/`domain`),
  counts and exception type names only.
- Consent is **not** needed (nothing goes to Claude).

// DontDraft.cs
public enum DontDraftKind { Sender, Domain }

/// <summary>Exact texts (SPEC 27.7).</summary>
public static class DontDraftTexts
{
    public const string NoAddress = "I couldn't find that sender's email address.";
    public const string OwnAddress = "That's your own address.";
    public const string OwnDomain =
        "That's your own organization's domain. To stop drafting for all internal mail, add it in Settings → AI drafts.";
    public const string Full =
        "\"Never draft for\" already has 200 entries. Remove some in Settings → AI drafts.";
    public const string AddButton = "Add";
    public const string CancelButton = "Cancel";

    /// <summary>"&lt;what&gt; is already on \"Never draft for\"."</summary>
    public static string Already(string what);
    /// <summary>"Never draft replies to anyone at &lt;domain&gt;?"</summary>
    public static string ConfirmHeading(string domain);
    /// <summary>Sender: "I won't draft replies to &lt;address&gt; any more. You can undo this in Settings → AI drafts."
    /// Domain: "I won't draft replies to anyone at &lt;domain&gt; any more. You can undo this in Settings → AI drafts."</summary>
    public static string Added(DontDraftKind kind, string entry);
    /// <summary>"AI drafts: added an entry to \"Never draft for\" (&lt;n&gt; entries)." with "1 entry" for n == 1 (invariant).</summary>
    public static string AddedEvent(int count);
}

/// <summary>Pure checks (SPEC 27.7). Never throw.</summary>
public static class DontDraftRules
{
    /// <summary>senderEmail trimmed when MailAddresses.LooksLikeSmtp; else null.</summary>
    public static string? SenderAddress(string? senderEmail);

    /// <summary>The part after the last '@', lower-case invariant, when it passes the SPEC 19.2 domain rule
    /// (SenderPattern.TryParse gives IsDomain); else null.</summary>
    public static string? Domain(string? address);

    /// <summary>address equals ownSmtp or mailboxSmtp (trimmed, OrdinalIgnoreCase; blank values never match).</summary>
    public static bool IsOwnAddress(string address, string? ownSmtp, string? mailboxSmtp);

    /// <summary>D = Domain(ownSmtp). True when domain == D, D ends with "." + domain (a parent of D), or domain ends
    /// with "." + D (a subdomain of D). Ordinal on lower-case values. False when D is null.</summary>
    public static bool IsOwnDomain(string domain, string? ownSmtp);

    /// <summary>Some entry parses (SenderPattern.TryParse) and Matches(address). Unparsable/null entries are skipped.
    /// Null list gives false.</summary>
    public static bool AddressCovered(IReadOnlyList<string?>? entries, string address);

    /// <summary>Some entry parses as a domain pattern P with domain == P.Value or domain ending with "." + P.Value.
    /// Address entries never cover a domain. Null list gives false.</summary>
    public static bool DomainCovered(IReadOnlyList<string?>? entries, string domain);

    /// <summary>entries.Count &gt;= AiDraftingSettings.MaxSenderEntries. Null gives false.</summary>
    public static bool IsFull(IReadOnlyList<string?>? entries);
}

/// <summary>The result of PrepareAsync. Exactly one of Entry and Balloon is non-null.</summary>
public sealed record DontDraftPrepared(DontDraftKind Kind, string? Entry, string? Balloon)
{
    /// <summary>Kind == Domain and Entry is not null.</summary>
    public bool NeedsConfirm => Kind == DontDraftKind.Domain && Entry is not null;
}

/// <summary>Both tray items (SPEC 27.7). Settings go through AiDraftingToggler.EditAi.</summary>
public sealed class DontDraftService
{
    /// <param name="live">() => settings.AiDrafting (read-only use in PrepareAsync).</param>
    /// <exception cref="ArgumentNullException">mailbox, indexes, toggler, live or hub is null.</exception>
    public DontDraftService(IAiMailbox mailbox, MailboxIndexes indexes, AiDraftingToggler toggler,
        Func<AiDraftingSettings> live, ActivityHub hub, ILogger? logger = null);

    /// <summary>Reads the selection and runs every check (see Behavior). Saves nothing.
    /// Never throws except OperationCanceledException for ct.</summary>
    public Task<DontDraftPrepared> PrepareAsync(DontDraftKind kind, CancellationToken ct);

    /// <summary>Appends prepared.Entry through EditAi, re-checking "covered" and the limit on the live copy.
    /// Returns the balloon text. Records the Ai event only when the entry was added. Never throws
    /// except as listed.</summary>
    /// <exception cref="ArgumentNullException">prepared is null.</exception>
    /// <exception cref="ArgumentException">prepared.Entry is null.</exception>
    public string Apply(DontDraftPrepared prepared);
}

## Behavior

### PrepareAsync(kind, ct)

In this order; the first step that gives a balloon ends it with
`new DontDraftPrepared(kind, null, <balloon>)`:

1. `sel = await mailbox.GetSelectedAsync(ct)`; null →
   `DraftTexts.ManualNoSelection` (`Select one email in Outlook first.`).
2. `email = await mailbox.ReadEmailAsync(sel.EntryId, ct)`; null →
   `DraftTexts.ManualNotInMailbox`
   (`That email isn't in your mailbox or an enabled shared mailbox.`).
3. `address = DontDraftRules.SenderAddress(email.Email.SenderEmail)`;
   null → `DontDraftTexts.NoAddress`.
4. `owner = await AiOwner.ResolveAsync(mailbox, indexes, WorkPriority.Interactive, ct)`;
   null → `AiTabTexts.OwnerUnknown` (Clippy can't check "own address"
   without it).
5. Sender: `IsOwnAddress(address, owner.Email, email.Mailbox)` →
   `DontDraftTexts.OwnAddress`. Domain: `domain = Domain(address)`;
   null → `DontDraftTexts.NoAddress`; `IsOwnDomain(domain, owner.Email)`
   → `DontDraftTexts.OwnDomain`. (`email.Mailbox` is `""` for the own
   mailbox, else the shared mailbox's SMTP.)
6. `entries = live().ExcludeSenders`. Sender: `AddressCovered(entries, address)`
   → `Already(address)`. Domain: `DomainCovered(entries, domain)` →
   `Already(domain)`.
7. `IsFull(entries)` → `DontDraftTexts.Full`.
8. Otherwise `new DontDraftPrepared(kind, address | domain, null)`.

Exceptions: `OperationCanceledException` when `ct` is cancelled is
rethrown. `OutlookUnavailableException` (incl. its subclasses) →
balloon `BalloonTexts.OutlookUnavailable`. Any other exception →
balloon `AiMenuTexts.ToggleFailed("something went wrong (" + type name + ")")`
and Warning
`AI drafts: "Don't draft for" failed ({Type}, HResult {HResult}).`
(never the message).

The sender address is stored exactly as trimmed (case kept); the domain
is lower-case. Consent is not checked.

### Apply(prepared)

```text
outcome = Added
errors = toggler.EditAi(ai =>
    list = ai.ExcludeSenders ??= []
    covered (same rule as step 6 for prepared.Kind) → outcome = Already; return false
    IsFull(list) → outcome = Full; return false
    list.Add(prepared.Entry); count = list.Count; return true)
```

- `errors` null: `Already(entry)` or `Full` per `outcome`.
- `errors` non-empty: `errors[0].Message` (e.g. a hand-edited invalid
  entry gives `Must be an email address or a domain like example.org.`).
  Nothing saved.
- Added: `hub.Event(ActivityKind.Ai, DontDraftTexts.AddedEvent(count))`
  (no mailbox), log Information
  `AI drafts: added a "Never draft for" entry ({Kind}), {Count} entries.`
  with `Kind` = `address`/`domain`; return `Added(prepared.Kind, entry)`.
- `IOException`/`UnauthorizedAccessException` from the save →
  `AiMenuTexts.ToggleFailed(ex.Message)` (balloon only, the same text the
  tray toggle uses; not logged). Any other exception →
  `AiMenuTexts.ToggleFailed("something went wrong (<Type>)")` + the
  Warning above.

### Rules details

- `IsOwnDomain`, own `me@cs.example.edu`: `cs.example.edu` (same),
  `example.edu` (parent), `lab.cs.example.edu` (subdomain) are own;
  `xcs.example.edu`, `s.example.edu`, `example.org` aren't. A one-label
  parent like `edu` can't occur (it fails the domain rule in step 5).
- `AddressCovered`: `contoso.example` and `@contoso.example` cover
  `ann@mail.contoso.example`; `ANN@contoso.example` covers
  `ann@contoso.example`.
- `DomainCovered`: `contoso.example` covers `mail.contoso.example`;
  `mail.contoso.example` doesn't cover `contoso.example`;
  `ann@contoso.example` covers no domain.

### Settings window (`SettingsEditor.Rebase`)

Add after the `EnabledAtUtc` line: when `live.AiDrafting.ExcludeSenders`
differs from the base's and the draft's list still equals the base's
(null as empty, ordinal `SequenceEqual`), the draft adopts a copy of the
live list. So a tray addition made while Settings is open survives OK/
Apply unless the user also edited the *Never draft for* box (then the
window wins, as §6.3 says). After Apply the form rebinds from live, so the
new line appears.

## Spec changes

Low-risk decisions made in this brief; add them to SPEC §27.7:
1. *Outlook not running* uses `BalloonTexts.OutlookUnavailable` ("It
   looks like Outlook isn't running. …"), not the manual draft's "I
   couldn't draft that reply: Outlook isn't running", which reads wrong
   for this action. No selection and not in an enabled mailbox use the
   manual draft's texts as written.
2. When Clippy doesn't know the user's address yet, both items show
   `AiTabTexts.OwnerUnknown` and add nothing (the own-address checks need
   it).
3. A sender domain that fails the §19.2 domain rule gives
   `I couldn't find that sender's email address.`
4. Order: the own-address/domain, "already" and 200-limit checks run
   before the domain confirmation dialog, and "already" and the limit
   run again on the live settings when the entry is added.
5. The event says `(1 entry)` for one entry, `(<n> entries)` otherwise.
6. Both items are disabled under the same conditions as *Draft a reply to
   the selected email* (no AI services, Outlook not running, rescan
   starting or running).
7. §6.3: a tray addition to *Never draft for* made while Settings is open
   is kept on OK/Apply unless the window's list was edited too (same
   three-way rule as the tray's Enabled toggle).
