# M13.1 Core meeting-times primitives

Base: `dev` after the M13 spec commit (`a5f98ea`). Core only, pure code,
no Outlook, no logging, no settings. It runs beside M13.3 and M13.5 and
touches none of their files. M13.2 (`find_free_times`) and M13.4
(`DraftWorker` step 6a) are the only callers; they are not part of this
task.

## Goal

Implement the pure building blocks of SPEC §21 (§21.2–§21.6, tests per
§21.9), used later by §11.8 and §19.7 step 6a:
- `OwnerCalendar.FromFreeBusy`: the owner's busy (code `2`) and
  tentative (code `1`) runs from the free/busy string of §8.
- `MeetingRanking`: tiers `busy` / `tentative` / `none` by 15-minute
  same-day adjacency, and the tier-then-start order (§21.2).
- `MeetingOffers`: exact-length candidates and selection (§21.3), the
  European office-hours split with continued numbering and the heading
  rules (§21.4), `FormatLine` and the text form (§21.5).
- `SenderRegion`: the Date-offset + TLD decision table and
  `CentralEurope()` (§21.4).
- `MeetingTimesHtml`: placeholder detection, insertion into sanitized
  HTML (breaks, no-placeholder paragraph rule) and the two failure
  placeholders (§21.6).

## Hard rules that apply here

- Pure functions only: no COM, no I/O, no `ILogger`, no `TimeProvider`.
  Callers (M13.2, M13.4) log; this code returns flags they can log from
  (`MeetingOfferSet.CetMissing`).
- No times, addresses or headers are ever logged (§21.6 "Logging"). This
  code logs nothing at all.
- Output HTML is built only from escaped text plus Clippy's own markup
  (`<p>`, `<br>`, `&nbsp;`, `DraftHtml.HighlightOpen/Close`). Model text
  (the heading) is cleaned and escaped; it never adds markup.
- Reuse, don't duplicate: `TimeRange` and `FreeBusy` (FreeBusy.cs),
  `TimeZoneLabels.Resolve` (§12), `MailText.Headers` (first value wins),
  `DraftHtml.HighlightOpen`/`HighlightClose`. Don't change
  `FreeBusy.BusyIntervals` (it treats `3` as busy for free-slot
  purposes; tiers are a separate reading of the same string).

## Behavior

### A. `OwnerCalendar.FromFreeBusy`

One pass over `fb`, like `FreeBusy.BusyIntervals` (reuse its `Make`
arithmetic: `start.AddMinutes((double)i * interval)`). Track the current
code-`2` run and code-`1` run separately; a code change closes the open
run. `'0' '3' '4' '5'` close both. Any other character → return
`Unknown` (don't throw). Closing runs at the end of the string. Because
runs of one code are maximal, they are already merged.

### B. `MeetingRanking`

- `IsAdjacent(r, i)`, with `tol = 15 min`:
  - after: `0 ≤ r.Start − i.End ≤ tol` **and** `r.Start.Date == LastDay(i)`;
  - before: `0 ≤ i.Start − r.End ≤ tol` **and** `i.Start.Date == LastDay(r)`;
  - `LastDay(x) = (x.End − 1 tick).Date` (the day that holds the last
    instant of the range, so a run ending at midnight belongs to the day
    before it).
  - Either case → true. Overlap gives a negative difference on both
    sides, so it's never adjacent.
- `TierOf`: `!owner.IsKnown` → `None`; any `Busy` run adjacent → `Busy`;
  else any `Tentative` run adjacent → `Tentative`; else `None`. A linear
  scan is fine (runs ≤ a few thousand; no perf target).
- `Rank`: materialise, compute tiers, `OrderBy(Tier).ThenBy(Start)`
  (LINQ `OrderBy` is stable).
- `Name`: `Busy → "busy"`, `Tentative → "tentative"`, `None → "none"`.

### C. `MeetingOffers.Candidates`

For each block `b` with `b.Duration ≥ duration`:
`for (s = b.Start; s + duration ≤ b.End; s += 30 min) add [s, s+duration)`,
then add `[b.End − duration, b.End)`. Remove duplicates (equal
`TimeRange`), sort by `Start` (then `End`). Blocks shorter than the
duration add nothing.

### D. `MeetingOffers.Select`

`ranked = MeetingRanking.Rank(candidates, owner)`; `taken = []`. Walk
`ranked`; skip a candidate that overlaps (`a.Start < b.End && b.Start < a.End`,
half-open, so touching is fine) any taken range or any `alreadyTaken`
range; otherwise take it. Stop at `count`. Return in taken order.

### E. `MeetingOffers.Build`

1. `cands = Candidates(freeBlocks, durationMinutes)`. Empty →
   `new MeetingOfferSet([], [], false, europe && centralEurope is null)`.
2. CET decision:
   - `cetMissing = europe && centralEurope is null`.
   - `cetShown = europe && centralEurope is not null && !SameOffset`,
     where `SameOffset` compares, at the **earliest candidate's start**
     `t0 = cands[0].Start`, `localZone.GetUtcOffset(t0)` with
     `centralEurope.GetUtcOffset(dto0)` and `dto0 = new DateTimeOffset(t0, localZone.GetUtcOffset(t0))`.
3. `ToCet(x) = TimeZoneInfo.ConvertTime(new DateTimeOffset(x, localZone.GetUtcOffset(x)), centralEurope).DateTime`
   (the offset form avoids `ConvertTime` throwing on a local time in a
   DST gap; `FreeTimeFinder.Iso` does the same).
4. Not `cetShown`: `main = Select(cands, owner, count)`, no second list.
5. `cetShown`: a candidate is *in hours* when `cs = ToCet(Start)`,
   `ce = ToCet(End)`, `cs ≥ cs.Date + 8h` and `ce ≤ cs.Date + 18h`
   (an end of exactly 18:00 counts; anything crossing CET midnight is
   out). `main = Select(inHours, owner, count)`. If
   `main.Count < count`: `second = Select(outHours, owner, count − main.Count, alreadyTaken: main ranges)`.
6. Number `main` 1…k, then `second` k+1…. For each option:
   `label = TimeZoneLabels.Resolve(labelOverride, localZone, Range.Start)`,
   `cet = cetShown ? new TimeRange(ToCet(Start), ToCet(End)) : null`,
   `Line = FormatLine(n, Range, label, cet)`, `List` = `Main` /
   `OutsideHours`.
7. Return `new MeetingOfferSet(main, second, cetShown, cetMissing)`.

### F. `MeetingOffers.FormatLine`

Invariant culture, exactly:
`$"{n}. {S:ddd} {S:M/d}  {S:HH:mm}–{E:HH:mm}"` (U+2013 between the
times, two spaces after the date), then `" " + localLabel.Trim()` unless
`localLabel` is null/whitespace, then, when `cet` is set,
`$"  ({cet.Start:HH:mm}–{cet.End:HH:mm} CET)"`. An end at midnight prints
`00:00` naturally (`HH:mm` of the next day's 00:00). The date is always
the start's date. No same-day check (unlike `SlotFormatter`).

### G. `MeetingOffers.Heading`

`null` → default. Otherwise, in the SPEC order:
1. remove every `char.IsControl` character;
2. collapse each run of `char.IsWhiteSpace` to one space;
3. remove `<`, `>`, `[`, `]`;
4. trim.
Valid when `1 ≤ Length ≤ 80` and it contains a `char.IsLetter`. Valid →
append `:` unless it already ends with `:`. Invalid → `OutsideHoursHeading`.

### H. `MeetingOfferSet.ToText`

`h = MeetingOffers.Heading(outsideHoursHeading)`. Main lines joined with
`"\n"`. When `OutsideHours` is non-empty: if `Main` is non-empty append
`"\n\n"`; then `h + "\n"` + its lines joined with `"\n"`. No trailing
newline. `Count == 0` → `""`.

### I. `SenderRegion`

- `DateOffset(v)`: null/blank → null. Remove one trailing comment:
  if the trimmed value ends with `)`, cut from the last `(` (and trim);
  no `(` → null. Take the last whitespace-separated token `t`.
  - `t` equals `GMT`, `UT`, `UTC` or `Z` (OrdinalIgnoreCase) → `0`.
  - `t` matches `^[+-][0-9]{4}$` (ASCII digits): `hh = t[1..3]`,
    `mm = t[3..5]`; `hh > 14 || mm > 59` → null; `t == "-0000"` → null;
    else `sign * (hh h + mm min)` (`"+0000"` → 0).
  - anything else → null.
- `Tld(smtp)`: null/blank or no `@` → `Generic`. Domain = text after the
  last `@`, trimmed, trailing `.` removed, lower-cased invariant; last
  label after the last `.` (the whole domain when there is no dot).
  In `EuropeanTlds` → `European`; exactly two ASCII letters →
  `OtherCountry`; else `Generic`.
- `IsEurope(smtp, headers)`: `MailText.Headers(headers)` →
  `TryGetValue("Date")` → `DateOffset`. Then, with `tld = Tld(smtp)`:
  - `OtherCountry` → false (every row).
  - offset `+01:00` or `+02:00` → `true` for `European` and `Generic`.
  - offset `+00:00` or `+03:00` → `tld == European`.
  - offset null → `tld == European`.
  - any other offset → false.
  Never throws (wrap nothing; the helpers don't throw).
- `CentralEurope()`: `Lazy<TimeZoneInfo?>` that tries
  `TimeZoneInfo.FindSystemTimeZoneById("Europe/Berlin")`, then
  `"W. Europe Standard Time"`, catching `TimeZoneNotFoundException` and
  `InvalidTimeZoneException` for each; null when both fail.

### J. `MeetingTimesHtml`

Placeholder regex (`[GeneratedRegex]`, `IgnoreCase | CultureInvariant`,
1000 ms timeout):

```
(?:<span style="background-color:#ffff00">\[\[ *meeting[ _-]times *\]\]</span>)|(?:\[\[ *meeting[ _-]times *\]\])
```

(the span text is `DraftHtml.HighlightOpen`/`HighlightClose`; write it
with `Regex.Escape` of those constants or keep a test that they agree.)
The highlighted alternative comes first so a highlighted placeholder is
replaced together with its span. A `RegexMatchTimeoutException` counts
as "no placeholder".

- `HasPlaceholder` → `IsMatch`.
- **Offer block** (`Insert`): escape each line (`&` → `&amp;`, `<` →
  `&lt;`, `>` → `&gt;`, in that order), then `Replace("  ", "&nbsp; ")`.
  Main lines joined with `<br>`. Second list: when main is non-empty
  `<br><br>`, then the escaped `MeetingOffers.Heading(outsideHoursHeading)`
  (same escape and `&nbsp; ` rule), `<br>`, its lines joined with `<br>`.
- **Failure block** (`InsertPlaceholder`): `DraftHtml.HighlightOpen` +
  escaped `placeholderText` + `DraftHtml.HighlightClose`.
- **Placing a block** (shared by both):
  - First regex match `m` → `before = html[..m.Index]`,
    `after = html[(m.Index + m.Length)..]`. Prefix `<br>` unless
    `before.TrimEnd()` is empty or ends with `<p>`, `<li>`,
    `<blockquote>` or `<br>` (OrdinalIgnoreCase). Suffix `<br>` unless
    `after.TrimStart()` is empty or starts with `</p>`, `</li>`,
    `</blockquote>` or `<br>`. Result
    `before + prefix + block + suffix + after`. Later matches are not
    touched.
  - No match: scan tags with `<(/?)([a-zA-Z][a-zA-Z0-9]*)[^>]*>`; `br`
    (and any self-closing `.../>`) doesn't change depth; a start tag
    increments, an end tag decrements (not below 0). Record the index of
    each `<p>` start tag seen at depth 0. ≥ 2 → insert
    `"<p>" + block + "</p>"` at the last recorded index; else append it
    at the end.
- `NoFreeTime(first, last)` →
  `$"[[add meeting times: no free time found between {first:yyyy-MM-dd} and {last:yyyy-MM-dd}]]"`
  (invariant). Which days M13.4 passes is M13.4's business.

### T2 `MeetingRankingTests`
Owner busy `Tue 10:00–11:00`.
1. Slot starting at the busy end (`11:00–12:00`) → `Busy`.
2. Slot ending at the busy start (`09:00–10:00`) → `Busy`.

8. `Rank` with owner busy `Fri 10:00–11:00` and tentative
   `Wed 12:00–13:00`, ranges (60 min each, in this input order)

### T3 `MeetingOffersTests` — candidates and selection

## Spec changes

None made. Clarifications decided in this brief (low-risk, inside the
spec's wording; the architect who owns SPEC.md may copy them into §21):

1. **"Same local day" (§21.2)**: for "R after I" the day is the day of
   I's last instant (`(I.End − 1 tick).Date`) compared with
   `R.Start.Date`; for "R before I" the day of R's last instant compared
   with `I.Start.Date`. So a run ending at midnight isn't adjacent to a
   range starting at 00:00 the next day.
2. **"The first candidate" (§21.4, owner already in CET)**: the earliest
   candidate by start, before selection.
3. **Only a second list (§21.4/§21.5)**: the text and HTML start with the
   heading; no leading blank line or `<br><br>`.
4. **Heading cleaning order (§21.4)** is applied literally: control
   characters are removed (a tab or newline disappears, it doesn't
   become a space), then whitespace is collapsed, then `<>[]` removed,
   then trimmed; the 1–80 length check is before the `:` is appended.
5. **Placeholder spaces (§21.6)**: "spaces inside the brackets" means
   ASCII spaces only, before/after the name (`[[ meeting_times ]]`);
   the separator is exactly one of `_`, space, `-`.
6. **`OwnerCalendar` for `null`/empty strings**: `null` → unknown; `""`
   → known with no runs (callers already treat short strings as
   unknown before calling).
7. **Escaping in inserted text** is `&`, `<`, `>` only (as
   `DraftHtml.Sanitize` does), so `couldn't` keeps its apostrophe.
