# M19.1 Daily token tally (schema 4)

Base: `dev` with M16 merged (schema 3, `DraftWorker.Revisit.cs`,
`DraftWorker.Rescan.cs`, the M16 pass/rescan log lines). May run beside
M18; see "Rebasing over M18" at the end. **No release for this task**
(the user, 2026-11-15: everything ships later as v0.1.1). Do not bump
`<Version>`, and ignore PLAN's "own PR and release" note.

## Goal

Make the cost of AI drafting visible (§19.13). Both backends report token
usage (`TokenUsage`) on `ModelResult.Ok` and on the `Failed` results that
come back after model work. Every caller tags its request with a
`ModelCallKind`. A `UsageRecordingModel` wrapped around the
`DraftModelSwitch` writes one `ai_calls` row per billed call into the own
mailbox index (new schema 4) and keeps today's totals in memory
(`AiUsage`). The total shows as a disabled first line in the tray's
**AI drafts** submenu and as a line under the Activity header, only while
AI drafts consent exists. The pass and rescan log lines get the pass's
token sums. Only counts are stored, never text.

SPEC refs: §19.13 (all of it), §6.2 (menu line), §6.4 (Activity line),
§9.1 (schema 4), §11.12 (`query_index` can't read `ai_calls`), §19.7 and
§23.9 (pass log line), §23.8 (rescan log line), §19.11 (logs: counts
only).

## Hard rules that apply here

- **Attachment content / mail text never enters the index.** `ai_calls`
  holds a time, a kind, a backend, an outcome and four integers. No
  prompt, output, subject, address or model name.
- **Never touch Claude credentials.** Token counts come only from the
  CLI's result envelope on stdout and the SDK response object. Nothing
  else is read. `modelUsage` and `total_cost_usd` are not read.
- **Logs never hold texts** (§19.11): the new log fields are integers;
  the Warning for a failed insert carries the exception type only.
- Recording never changes a model result and never throws into a caller.

// DraftModel.cs
/// <summary>Token counts of one call (SPEC 19.13). Null = unknown.</summary>
public sealed record TokenUsage(long? Input, long? Output, long? CacheRead, long? CacheCreation)
{
    /// <summary>Input or Output is not null.</summary>
    public bool Known => Input is not null || Output is not null;
}

public enum ModelCallKind { Draft, Manual, Revisit, Rescan, Style }

public sealed record ModelRequest(string SystemPrompt, string UserPrompt, string JsonSchema,
    string Model, string Effort, TimeSpan Timeout, int MaxOutputTokens,
    ModelCallKind Kind = ModelCallKind.Draft);

// in ModelResult (InputTokens/OutputTokens stay; existing callers compile unchanged)
public sealed record Ok(JsonElement Output, TimeSpan Duration, int? InputTokens, int? OutputTokens,
    TokenUsage? Usage = null) : ModelResult;
public sealed record Failed(ModelFailure Kind, int? Code, TokenUsage? Usage = null) : ModelResult;

// AiUsage.cs
/// <summary>Sums over calls. Null token values count as 0. UnknownCalls = calls with Input and Output both null.</summary>
public sealed record AiUsageTotals(int Calls, int UnknownCalls, long Input, long Output, long CacheRead, long CacheCreation)
{
    public static AiUsageTotals Zero { get; } = new(0, 0, 0, 0, 0, 0);
    public long In => Input + CacheRead + CacheCreation;
    public long Out => Output;
    public long Total => In + Out;
    /// <summary>One more call. usage null or !Known counts as unknown; its non-null fields are still summed.</summary>
    public AiUsageTotals Add(TokenUsage? usage);
    /// <summary>Add(UsageRecordingModel.UsageOf(result)) when UsageRecordingModel.IsRecorded(result); else this.</summary>
    /// <exception cref="ArgumentNullException">result is null.</exception>
    public AiUsageTotals AddCall(ModelResult result);
}

/// <summary>Today's totals in memory, backed by the own index's ai_calls (SPEC 19.13). Thread-safe.</summary>
public sealed class AiUsage
{
    /// <param name="ownIndex">() => indexes.For(MailboxIndexes.OwnMailbox). Called on each Load/Record.</param>
    /// <exception cref="ArgumentNullException">ownIndex or zone is null.</exception>
    public AiUsage(Func<EmailIndex> ownIndex, TimeZoneInfo zone, TimeProvider? time = null, ILogger? logger = null);

    /// <summary>Sets today's totals to ownIndex().AiUsageSince(local midnight). Never throws (Warning, type only;
    /// totals stay Zero).</summary>
    public void Load();

    /// <summary>at = time.GetUtcNow(). Inserts one row (AddAiCall), then adds to today's totals. The in-memory
    /// add happens even when the insert fails (Warning, type only). Never throws.</summary>
    public void Record(ModelCallKind kind, AiBackend backend, bool ok, TokenUsage? usage);

    /// <summary>Today's totals. The first read (or Record) after local midnight resets them to Zero first.</summary>
    public AiUsageTotals Today();

    /// <summary>"cli" for ClaudeCode, "api" for ApiKey.</summary>
    /// <exception cref="ArgumentOutOfRangeException">backend isn't defined.</exception>
    public static string BackendName(AiBackend backend);

    /// <summary>Local midnight of now's local day, as UTC. An invalid local midnight (DST gap) moves 1 h later
    /// (the DraftWorker.LocalMidnightUtc rule, copied; DraftWorker is not refactored).</summary>
    internal static DateTimeOffset LocalMidnightUtc(DateTimeOffset now, TimeZoneInfo zone);
}

/// <summary>Wraps the DraftModelSwitch in Program (SPEC 19.13).</summary>
public sealed class UsageRecordingModel : IDraftModel
{
    /// <exception cref="ArgumentNullException">inner, settings or usage is null.</exception>
    public UsageRecordingModel(IDraftModel inner, Func<AiDraftingSettings> settings, AiUsage usage, ILogger? logger = null);

    /// <summary>inner.CheckAsync, nothing recorded.</summary>
    public Task<ModelStatus> CheckAsync(CancellationToken ct);

    /// <summary>Reads settings().Backend, awaits inner.RunAsync, records when IsRecorded, returns the inner result
    /// unchanged (same instance). Exceptions from inner propagate unrecorded.</summary>
    public Task<ModelResult> RunAsync(ModelRequest request, CancellationToken ct);

    /// <summary>True for Ok, and Failed with Kind Timeout, BadOutput, NoStructuredOutput, ProcessExit or Http.
    /// False for RateLimited, NotSignedIn, Failed NotInstalled/BadInput/Cancelled, null and anything else.</summary>
    public static bool IsRecorded(ModelResult? result);

    /// <summary>Ok.Usage or Failed.Usage; else null.</summary>
    public static TokenUsage? UsageOf(ModelResult? result);
}

## Behavior

### Usage parsing

- **CLI** (`ClaudeCliOutput.ParseCore`): when the envelope has a `usage`
  object, build `TokenUsage` from `input_tokens`, `output_tokens`,
  `cache_read_input_tokens`, `cache_creation_input_tokens`, each with
  `ValueKind == Number && TryGetInt64(out v) && v >= 0`, else null. No
  `usage` object (or not an object) gives `Usage = null`. The existing
  `inTok`/`outTok` (`TryGetInt32`) stay exactly as they are, so
  `Ok.InputTokens`/`OutputTokens` don't change. Attach the usage to the
  `Ok` results and to **every** `Failed` returned while `owner` is not
  null (the success-path `NoStructuredOutput`, the error-path
  `NoStructuredOutput` for `error_max_structured_output_retries`, and
  `ProcessExit`). `RateLimited`/`NotSignedIn` get nothing (they have no
  field). The not-JSON `BadOutput` and the catch-all `BadOutput` have no
  envelope: `Usage` null.
- **API** (`AnthropicApiModel.RunCoreAsync`): right after
  `Messages.Create` returns, read `msg.Usage.InputTokens`,
  `OutputTokens` (`long`), `CacheReadInputTokens`,
  `CacheCreationInputTokens` (`long?`, SDK 13.3.0), each in its own
  `try`/`catch (Exception)` (error → null), negative → null. Attach to
  the `Ok` and to the three 2xx failures: `refusal` →
  `Failed(NoStructuredOutput, null, usage)`, `max_tokens` →
  `Failed(BadOutput, null, usage)`, text not a JSON object or
  `JsonException` → `Failed(NoStructuredOutput, null, usage)`. The outer
  `catch` paths (HTTP errors, timeouts, `AnthropicInvalidDataException`)
  have no message: no usage. The existing `inTok`/`outTok` and the log
  line stay. `Kind` never reaches the wire (the request-body shape test
  keeps passing unchanged).

### Recording

- `UsageRecordingModel.RunAsync`: `ArgumentNullException` for a null
  request. Read `settings().Backend` in a `try` before the call (an
  exception → no recording for this call, Warning
  `AI usage: couldn't read the backend ({Type}).`). Await
  `inner.RunAsync(request, ct)`. When `IsRecorded(result)`:
  `usage.Record(request.Kind, backend, result is ModelResult.Ok, UsageOf(result))`
  inside `try`/`catch (Exception)` (Warning
  `AI usage: couldn't record a call ({Type}).`). Return the inner
  result object unchanged.
- `AiUsage.Record`: `at = time.GetUtcNow()` (when the call returned);
  `ownIndex().AddAiCall(at, kind, BackendName(backend), ok, usage)` in
  `try`/`catch` (Warning `AI usage: couldn't record a call ({Type}).`);
  then, under the lock, roll over if needed and `_today = _today.Add(usage)`.
- Only the own index is written. Shared indexes get the table by
  migration but never a row.
- `ai_calls` is independent of `ModelCallsSince`/`DailyCap`/the Settings
  "Today" line: those don't change.

### Schema 4

```sql
CREATE TABLE IF NOT EXISTS ai_calls (
  id INTEGER PRIMARY KEY,
  at INTEGER NOT NULL,
  kind TEXT NOT NULL,
  backend TEXT NOT NULL,
  outcome TEXT NOT NULL,
  input INTEGER, output INTEGER, cache_read INTEGER, cache_creation INTEGER);
CREATE INDEX IF NOT EXISTS ix_ai_calls_at ON ai_calls(at);
```

`Step4` executes this DDL (`IF NOT EXISTS`, like `Step3`). Migrations
array becomes `[Step1, Step2, Step3, Step4]`. A new file goes 0 → 4 in
one transaction; a schema-3 file gets only `Step4`; rows of every other
table are untouched. The newer-schema refusal text is the existing one
(now "supports up to 4").

`AiUsageSince` SQL (one statement, `@s` = `since.ToUnixTimeSeconds()`):

```sql
SELECT COUNT(*),
       COALESCE(SUM(CASE WHEN input IS NULL AND output IS NULL THEN 1 ELSE 0 END), 0),
       COALESCE(SUM(input), 0), COALESCE(SUM(output), 0),
       COALESCE(SUM(cache_read), 0), COALESCE(SUM(cache_creation), 0)
FROM ai_calls WHERE at >= @s
```

Purge: `PurgeDecisions(now)` adds
`DELETE FROM ai_calls WHERE at < @t` (same `@t` = now − 30 days, same
transaction, counted in the returned total). `PurgeOlderThan` adds the
same delete next to its `ai_revisits` delete (same `DateTimeOffset.UtcNow`
rule as the lines around it).

`query_index` needs no code change: the authorizer denies every table
that isn't one of its views. The security test proves it for `ai_calls`.

### Today's totals

- Local day = `TimeZoneInfo.ConvertTime(now, zone)` date. `AiUsage`
  keeps `(_day, _today)`. `Today()` and `Record` first compare the
  current local day with `_day`; when different, `_today = Zero`,
  `_day = current`. `Load()` sets both from
  `AiUsageSince(LocalMidnightUtc(now, zone))`.
- `Program` calls `Load()` once, synchronously, right after building
  `AiUsage` and before the `DraftWorker` and `StyleSkill` exist, so no
  call can race it (one indexed query on a small table).
- The UI only calls `Today()` (memory, a lock). It never queries SQLite.
- A Rebuild of the own index drops the `ai_calls` rows; the in-memory
  totals keep counting until the next start. Accepted.

### Texts

`AiUsageTexts.Today(t)` (all numbers invariant; counts with `N0`;
`call` when Calls is 1, else `calls`):
- `t.Calls == 0` → `Today: no AI calls`
- `t.UnknownCalls >= t.Calls` → `Today: <n> AI call(s), tokens unknown`
- else `Today: <n> AI call(s), ~<Format(Total)> tokens (in <Format(In)> / out <Format(Out)>)`
  plus `, <u> without token data` when `UnknownCalls > 0` (u with `N0`).

Examples: `Today: 18 AI calls, ~210k tokens (in 190k / out 20k)`;
`Today: 1 AI call, ~1.2k tokens (in 1k / out 234)`;
`Today: 3 AI calls, ~12k tokens (in 10k / out 2k), 1 without token data`;
`Today: 2 AI calls, tokens unknown`.

`TokenCount.Format(n)` (use `decimal` math and
`Math.Round(x, d, MidpointRounding.AwayFromZero)`, format with
`CultureInfo.InvariantCulture`, no thousands separators):
1. `n < 0` → `n = 0`.
2. `n < 1_000` → `n` (`999`).
3. `k1 = Round(n / 1000m, 1)`; if `n < 100_000` and `k1 < 100` →
   `k1` with a trailing `.0` dropped + `k` (`1k`, `1.2k`, `12.3k`).
4. `k0 = Round(n / 1000m, 0)`; if `n < 1_000_000` and `k0 < 1000` →
   `k0` + `k` (`100k` for 99,950 and 100,000; `210k`; `999k` for 999,499).
5. else `m1 = Round(n / 1_000_000m, 1)` with `.0` dropped + `M`
   (`1M` for 999,500 and 1,000,000; `1.2M`; `3M`).

`UnknownCallsLogDetail(u)`: `""` for `u <= 0`, else
`, <u> calls without token data` (exactly that word "calls", invariant
integer).

### Log lines

Append to the end of both templates (after `{Ms} ms`), keeping every
existing placeholder and argument:

```
, tokens in {TokensIn} out {TokensOut}{UnknownTokens}
```

with arguments `p.Usage.In`, `p.Usage.Out` (raw `long`s, no
formatting) and `AiUsageTexts.UnknownCallsLogDetail(p.Usage.UnknownCalls)`.
Always present, also when the pass made no calls (`tokens in 0 out 0`).
The `Ai` summary events and balloons don't change.

`PassState` gets `public AiUsageTotals Usage { get; set; } = AiUsageTotals.Zero;`.
Right after each of the two `RunAsync` calls that have a `PassState`
(automatic path in `DraftWorker.cs`, revisit in `DraftWorker.Revisit.cs`),
add exactly one line: `p.Usage = p.Usage.AddCall(result);`. A rescan
uses one `PassState` for its emails and their revisits, so the rescan
line sums both. The manual path has no log line change.

The worker counts from the results it receives, with the same
`IsRecorded` rule the wrapper uses, so the log is right with or without
the wrapper (tests use `FakeDraftModel` directly).

## Spec changes

Low-risk decisions made in this brief; add them to SPEC §19.13:
1. CLI: `Usage` is null when the envelope has no `usage` object; a
   present object with no valid field gives a `TokenUsage` of nulls.
2. `PurgeOlderThan` deletes old `ai_calls` rows too, like the other AI
   tables.
3. The in-memory total counts a call even when its row insert failed.
4. `AiUsage.Load()` runs once, synchronously, at start-up before the
   drafting worker exists. After a Rebuild of the own index the
   in-memory total keeps counting until the next start.
5. The log suffix is always written (`, tokens in 0 out 0` for a pass
   without calls).
6. `AiUsageTexts.Today` writes `1 AI call` (singular) and counts with
   thousands separators (`1,234 AI calls`); `TokenCount.Format` treats
   negative input as 0.
7. The Activity line and the tray line are hidden (not empty) without
   consent.
