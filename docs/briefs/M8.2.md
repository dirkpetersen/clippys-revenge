# M8.2 `GetFreeBusy` + `find_free_times`

## Goal

Implement the `find_free_times` MCP tool (SPEC §11.8) and the COM free/busy
read behind it (§8 `GetFreeBusy`), reusing the M1 helpers `Recipients.Parse`,
`FreeBusy.BusyIntervals` / `FreeSlots` / `ChunkStarts` / `JoinChunks`,
`SlotFormatter.Format`, `TimeZoneLabels.Resolve` and `SearchDates.ParseFrom`
(§12, §11.1). The App does only the COM part (resolve one address, read
the 28-day chunks, read the current user's SMTP address). It runs on the
`OutlookWorker` at Interactive priority (§4). Everything else goes in a Core
`FreeTimeFinder` behind a small `IFreeBusySource` interface, so it can be
tested on Linux with a fake: argument defaults and bounds, attendee list
and owner, the unknown-attendee rules, slot search and formatting, and the
result shape. Settings that apply: `WorkStartHour`, `WorkEndHour`,
`BusinessDaysOnly`, `TimeZoneLabel`, `TentativeIsBusy` (§5.2). Performance
target (§17): 8 attendees over 10 business days in under 5 s.

namespace ClippysRevenge.Core;

public interface IFreeBusySource
{
    /// The signed-in user (own mailbox owner). Email is a primary SMTP address.
    /// <exception cref="McpException">Outlook unavailable, or no SMTP address.</exception>
    Task<Recipient> GetCurrentUserAsync(CancellationToken ct);

    /// Joined free/busy string starting at from.Date, at intervalMinutes per
    /// character, covering at least [from.Date, to). Null = unknown attendee
    /// (unresolvable, no free/busy, or a chunk error).
    /// <exception cref="McpException">Outlook unavailable.</exception>
    Task<string?> GetFreeBusyAsync(string email, DateTime from, DateTime to,
                                   int intervalMinutes, CancellationToken ct);
}

public sealed record FreeTimeRequest(
    string? Recipients,
    int DurationMinutes = 60,
    int DaysAhead = 10,

    int? EarliestHour = null,
    int? LatestHour = null,
    bool? BusinessDaysOnly = null,
    bool IncludeMe = true,
    int MaxSuggestions = 5,
    string? Mailbox = null);

public sealed record FreeTimeSuggestion(
    [property: JsonPropertyName("n")] int N,
    [property: JsonPropertyName("label")] string Label,
    [property: JsonPropertyName("start")] string Start,   // yyyy-MM-ddTHH:mm:sszzz
    [property: JsonPropertyName("end")] string End);

public sealed record FreeTimeAttendee(
    [property: JsonPropertyName("name")] string Name,
    [property: JsonPropertyName("email")] string Email);

    [property: JsonPropertyName("suggestions")] IReadOnlyList<FreeTimeSuggestion> Suggestions,
    [property: JsonPropertyName("text")] string Text,
    [property: JsonPropertyName("unknown_attendees")] IReadOnlyList<string> UnknownAttendees,
    [property: JsonPropertyName("attendees")] IReadOnlyList<FreeTimeAttendee> Attendees);

public sealed class FreeTimeFinder(IFreeBusySource source, TimeProvider time, TimeZoneInfo timeZone)

}

## Behavior

### `FreeBusy.FetchChunked`

1. Validate `intervalMinutes` (same rule and exception as `JoinChunks`) and
   `fetchChunk` first.
2. `starts = ChunkStarts(from, to)`. Empty → return `""`.
3. Call `fetchChunk(s)` for each start in order. On the first `null`, return
   `null` and don't fetch the remaining chunks.
4. Return `JoinChunks(chunks, intervalMinutes)`. Catch only the plain
   `ArgumentException` it throws for a short non-last chunk, and return
   `null` (the attendee is unknown, §12). Interval validation already ran
   in step 1.

### `FreeTimeFinder.FindAsync`

All validation in steps 1–7 runs **before any source call**. Every
argument error is an `McpException` with the exact message given.

1. **Recipients.** `Recipients.Parse(request.Recipients ?? "")`. On
   `FormatException`, throw `McpException(ex.Message)`. The text is SPEC
   §12's `Recipient "<entry>" has no valid email address. Use "Name <email>" or a bare email, and separate recipients with ";".`
   More than `MaxAttendees` (50) parsed recipients →
   `find_free_times takes at most 50 attendees; got <n>.`
2. **Duration.** If it's outside 1–1440:
   `duration_minutes must be between 1 and 1440.`
3. **Hours.** `start = EarliestHour ?? settings.WorkStartHour` and
   `end = LatestHour ?? settings.WorkEndHour`. Check in this order:
   - start not in 0–23: `earliest_hour must be between 0 and 23.`
   - end not in 1–24: `latest_hour must be between 1 and 24.`
   - end ≤ start: `latest_hour must be later than earliest_hour.`
4. **Clamps (no error).** `days = Math.Clamp(DaysAhead, 1, 60)`,
   `max = Math.Clamp(MaxSuggestions, 1, 20)`, and
   `businessDays = BusinessDaysOnly ?? settings.BusinessDaysOnly`.
5. **Now and range.**
   - `now = TimeZoneInfo.ConvertTime(time.GetUtcNow(), timeZone).DateTime`
     (local wall clock).
   - `DateFrom` goes through `SearchDates.ParseFrom(DateFrom, timeZone)`.
     On `FormatException`, throw `McpException(ex.Message)`. It is the §11.1
     `date_from "<text>" is not a valid date. Use an ISO date like 2026-03-01 or a date-time like 2026-03-01T14:30 (local time).`
   - A parsed value becomes `from = TimeZoneInfo.ConvertTime(dto, timeZone).DateTime`.
     A blank value means `from = now`.
   - `to = from.Date.AddDays(days)`. `days_ahead` counts **calendar days**,
     starting with the day of `from`.
6. **Mailbox.** `key = MailboxIndexes.Normalize(request.Mailbox)`.
   - If `key != ""`, look up `settings.FindSharedMailbox(key)`. When it
     is null, not `Enabled`, or `key == "all"`, throw
     `MailboxIndexes.MailboxError(request.Mailbox, keys)`. `keys` is `""`
     followed by the trimmed, lower-cased `Smtp` of every enabled shared
     mailbox, in settings order.
   - The mailbox is validated even when `IncludeMe` is false.
7. **Empty.** No parsed recipients and `IncludeMe == false` →
   `find_free_times needs at least one attendee. Pass recipients as "Name <email>; ..." or set include_me=true.`
8. **Owner** (only when `IncludeMe`):
   - Own mailbox (`key == ""`): `await source.GetCurrentUserAsync(ct)`.
   - Shared mailbox: `new Recipient(sm.DisplayName.Trim(), sm.Smtp.Trim())`,
     with no source call.
   - Append the owner to the attendee list unless an attendee with the same
     email (`OrdinalIgnoreCase`) is already in it. The attendee list is the
     parsed recipients in order, then the owner.
9. **Free/busy.** `interval = FreeBusy.DefaultIntervalMinutes` (30),
   `needed = ceil((to - from.Date).TotalMinutes / interval)`.
   - For each attendee, **sequentially, in list order**, call
     `await source.GetFreeBusyAsync(a.Email, from, to, interval, ct)`.
   - The attendee is **unknown** when the result is null or empty, when
     `Length < needed` (time not covered must never count as free), or when
     `FreeBusy.BusyIntervals(fb, from.Date, interval, settings.TentativeIsBusy)`
     throws `FormatException`.
   - Otherwise keep the busy list.
   - `McpException`s (Outlook unavailable) and `OperationCanceledException`
     from the source propagate unchanged. No other exception is caught.
10. **Slots.**
    - If no attendee is known, there are no slots.
    - Otherwise call
      `FreeBusy.FreeSlots(knownBusyLists, from, to, start, end, businessDays, duration, now, interval)`
      and take the first `max` slots in chronological order. Each slot is a
      whole free block, as `FreeSlots` returns it. Don't split blocks.
11. **Formatting.** For slot `i` (1-based):
    - `label = SlotFormatter.Format(i, s.Start, s.End, TimeZoneLabels.Resolve(settings.TimeZoneLabel, timeZone, s.Start), start, end)`.
    - `Start`/`End` are `new DateTimeOffset(x, timeZone.GetUtcOffset(x)).ToString("yyyy-MM-dd'T'HH:mm:sszzz", CultureInfo.InvariantCulture)`.
    - `N = i`.
12. **Result.**
    - `Attendees`: the known attendees, as `{Name, Email}` in list order.
      `Name` is the parsed name (`""` for a bare email).
    - `UnknownAttendees`: the emails of the unknown attendees, in list
      order, as given.
    - `Text`:
      - With suggestions, the labels joined with `"\n"`.
      - With no known attendee:
        `No free/busy information could be read for any attendee, so no times can be suggested. Check the addresses in unknown_attendees.`
      - Otherwise:
        `No free time of at least <duration> minutes was found for everyone between <d1> and <d2>. Try a larger days_ahead, a shorter duration_minutes, or a wider earliest_hour/latest_hour.`
        Here `d1 = from.Date` and `d2 = to.AddDays(-1).Date`, both formatted
        `yyyy-MM-dd` with the invariant culture.
13. The finder keeps no state between calls (§11.8). It reads the
    `Settings` values once, at the start of the call.

### App

- **`OutlookCalendar.GetFreeBusy`** (§8):
  - Call `app.Session.CreateRecipient(email)`, then `Resolve()`. If
    `!Resolved`, return `null`.
  - Otherwise take `AddressEntry` and return
    `FreeBusy.FetchChunked(from, to, intervalMinutes, s => addressEntry.GetFreeBusy(s, intervalMinutes, true))`.
    The third argument `true` gives the complete 0–4 codes.
  - Release `Recipient`, `AddressEntry` and the `Session` reference with
    `Marshal.ReleaseComObject` in `finally`.
  - Catch `COMException` (from `Resolve` or `GetFreeBusy`, e.g. external
    addresses or the security guard): rethrow it when
    `ComErrors.IsOutlookGone(ex)`, otherwise return `null`. Catch nothing
    else.
- **`OutlookCalendar.GetCurrentUser`**:
  - Read `Session.CurrentUser`. `name = CurrentUser.Name ?? ""`.
  - `email = CurrentUser.AddressEntry.GetExchangeUser()?.PrimarySmtpAddress`,
    falling back to `AddressEntry.Address`.
  - If the result is blank or has no `@` (an X500 DN), throw
    `McpException("Could not read your own email address from Outlook, so include_me can't be used. Add your address to recipients and set include_me=false.")`.
  - Release COM objects in `finally`.
- **`OutlookFreeBusySource`**: each method is one
  `worker.RunAsync(app => OutlookCalendar.X(app, …), WorkPriority.Interactive, ct)`.
- **Program**: in `ConfigureServices`, add
  `.AddSingleton<IFreeBusySource>(new OutlookFreeBusySource(worker))` and
  `.AddSingleton(sp => new FreeTimeFinder(sp.GetRequiredService<IFreeBusySource>(), TimeProvider.System, TimeZoneInfo.Local))`,
  using the worker instance M5.1 creates.
- **Tool description** (verbatim):
  `Finds meeting times when everyone is free, from Outlook free/busy. Paste recipients as "Last, First <email>; ..." (separate with ";"). Returns numbered suggestions with start/end (local time, ISO with offset) and a ready-to-show "text". People whose free/busy can't be read (e.g. outside the organization) are listed in unknown_attendees and ignored. Nothing is booked. To book suggestion N, pass its start and end to send_meeting_invite.`
- **Parameter descriptions**:
  - `recipients`: `Attendees as "Name <email>; Name <email>". Split on ";" only.`
  - `duration_minutes`: `Minimum free block length, 1-1440.`
  - `days_ahead`: `Calendar days to search, starting with date_from's day (max 60).`
  - `date_from`: `Start date or date-time, local time (ISO). Default: now.`
  - `earliest_hour` / `latest_hour`: `Working-hours window, 0-23 / 1-24. Default: tray settings.`
  - `business_days_only`: `Skip Saturdays and Sundays. Default: tray settings.`
  - `include_me`: `Also check the calendar owner (you, or the shared mailbox).`
  - `max_suggestions`: `1-20.`
  - `mailbox`: `Empty = your calendar; or the SMTP address of an enabled shared mailbox.`
- No new activity events. The host's tool filter already records the
  `Tool` event (§18 M4.1).

  `GetCurrentUserAsync` calls (returning a configured
