# M2.4 `MailboxIndexes`: per-mailbox files, `all` merge, `Locate`, add/disable/remove

## Goal

Implement `MailboxIndexes` in Core (SPEC §9.3, file paths §5.1, `mailbox`
argument rules §11 intro, tests §15 row `MailboxIndexes`, decision in §18
"Unchecking a shared mailbox sets `Enabled = false`"). It holds one
`EmailIndex` (M2.1–M2.3) per enabled mailbox: key `""` for the own mailbox
(`index.db`) and the lower-cased SMTP address for shared ones
(`index-<smtp>.db`). It resolves a tool's `mailbox` argument (`For`), searches
one mailbox or `all` with a date-ordered merge and paging applied after the
merge (`Search`), finds which mailbox holds an EntryID (`Locate`), and lets the
tray/settings add, disable and remove shared mailboxes. No COM, no settings
I/O, no sync logic.

## Public API

Namespace `ClippysRevenge.Core`, file-scoped.

```csharp
using ModelContextProtocol;   // McpException

/// One search row tagged with the mailbox key it came from ("" = own).
public sealed record MailboxHit(string Mailbox, EmailSummary Email);

/// Result of Locate: the mailbox key ("" = own) and the indexed row.
public sealed record LocatedEmail(string Mailbox, EmailDetail Email);

public sealed class MailboxIndexes : IDisposable
{
    public const string OwnMailbox = "";
    public const string AllMailboxes = "all";
    public const string OwnFileName = "index.db";

    /// Opens (creating if needed) dataDir/index.db and one index per shared
    /// address, in the given order. Duplicates (after Normalize) are ignored.
    /// Creates dataDir if missing.
    /// ArgumentException: dataDir null/whitespace; a shared entry that
    ///   normalizes to "" or "all" or has no '@'.
    public MailboxIndexes(string dataDir, IEnumerable<string> enabledSharedMailboxes);

    /// "" (own) first, then shared keys in the order they were added. Snapshot.
    public IReadOnlyList<string> Mailboxes { get; }

    /// null/whitespace -> ""; trimmed, lower-cased (invariant) otherwise.
    /// "ALL" -> "all". Never throws.
    public static string Normalize(string? mailbox);

    /// "" -> Path.Combine(dataDir, "index.db");
    /// otherwise Path.Combine(dataDir, "index-" + FileNames.SafeFileName(Normalize(mailbox)) + ".db").
    /// ArgumentException when mailbox normalizes to "all".
    public static string PathFor(string dataDir, string? mailbox);

    /// The index for one mailbox (Normalize applied).
    /// McpException: "all", or not configured / not enabled (messages below).
    public EmailIndex For(string? mailbox);

    /// "" -> own; address -> that mailbox; "all" -> every enabled mailbox,
    /// merged newest first, then f.Offset/f.Limit applied to the merged list.
    /// McpException: unknown / disabled mailbox (same message as For).
    public IReadOnlyList<MailboxHit> Search(SearchFilter f, string? mailbox);

    /// Own index first, then shared in Mailboxes order. null when no enabled
    /// index has the id, or entryId is null/whitespace. Never throws McpException.
    public LocatedEmail? Locate(string? entryId);

    /// Opens the index for a shared mailbox (idempotent: returns the existing
    /// instance when already enabled). Add("") returns the own index.
    /// ArgumentException: normalizes to "all" or has no '@'.
    public EmailIndex Add(string mailbox);

    /// Stops using a shared mailbox: removes it from Mailboxes and Close()s
    /// it; the file stays. false when it was not enabled.
    /// ArgumentException: mailbox normalizes to "" or "all".
    public bool Disable(string mailbox);

    /// Disable (if enabled), then when deleteFile is true deletes
    /// PathFor(dataDir, mailbox) and its "-wal" and "-shm" files (missing files
    /// are fine). Works for a mailbox that is already disabled.
    /// ArgumentException: mailbox normalizes to "" or "all".
    /// IOException / UnauthorizedAccessException from File.Delete propagate.
    public void Remove(string mailbox, bool deleteFile);

    /// Close()s every open index. Idempotent. Further calls -> ObjectDisposedException.
    public void Dispose();
}
```

`DataDir` is not exposed. Keep any other helper `private` or `internal`.

## Behavior

1. **Keys.** All public methods apply `Normalize` to the mailbox argument.
   Keys in `Mailboxes` are normalized. Lookups are therefore case- and
   whitespace-insensitive: `For(" Help@X.edu ")` is the same instance as
   `For("help@x.edu")`. A shared key must contain `@` (no further address
   validation; `Settings.Validate` already does that).
2. **Paths** (§5.1): own → `index.db`; shared → `index-<smtp>.db` with
   `<smtp>` lower-cased and passed through `FileNames.SafeFileName`. Example:
   `Helpdesk@OregonState.edu` → `index-helpdesk@oregonstate.edu.db`.
3. **Own mailbox** is always open and always first. It cannot be disabled or
   removed through this class (rebuild is M6.1's job).
4. **`For` errors** (exact text; `{input}` is the caller's argument trimmed,
   `null` shown as empty; `{list}` is every key in `Mailboxes` order, each in
   double quotes, joined with `", "`, with the own key written as
   `"" (your own mailbox)`):
   - unknown or disabled:
     `Mailbox "{input}" is not configured or not enabled. Available mailboxes: {list}. To use another shared mailbox, ask the user to enable it in the Clippy tray menu under Shared mailboxes.`
   - `all`:
     `Mailbox "all" only works with search tools. Use one mailbox: {list}.`

   Example with one shared mailbox, `For("x@y.org")`:
   `Mailbox "x@y.org" is not configured or not enabled. Available mailboxes: "" (your own mailbox), "helpdesk@x.edu". To use another shared mailbox, ask the user to enable it in the Clippy tray menu under Shared mailboxes.`

   Truncate `{input}` to its first 100 characters (append nothing).
5. **`Search`, single mailbox:** call `For(mailbox).Search(f)` unchanged and
   tag each row with the key. Order and paging are whatever `EmailIndex` does.
6. **`Search`, `all`:**
   - `limit = f.Limit`, `offset = max(f.Offset, 0)`. If `limit <= 0` return
     an empty list without querying. Do **not** cap `limit` here (the tool
     layer caps it at 200, §11.1).
   - `need = offset + limit` (compute in `long`; if above `int.MaxValue`, use
     `int.MaxValue`).
   - For each mailbox in `Mailboxes` order, fetch its first `need` rows in
     chunks: `o = 0`; while fewer than `need` collected:
     `page = min(200, need - collected)`; `rows = index.Search(f with { Offset = o, Limit = page })`;
     append; stop if `rows.Count < page`; `o += rows.Count`. (Chunking makes
     the merge correct even if `EmailIndex.Search` caps `Limit` at 200.)
   - Concatenate in mailbox order, **stable** sort by event time descending
     (`OrderByDescending`, which is stable), then `Skip(offset).Take(limit)`.
     Ties therefore go own first, then shared in `Mailboxes` order, then the
     order the index returned.
   - The snapshot of open indexes is taken under the lock; queries run
     outside it.
7. **`Locate`:** `Get(entryId)` on own, then each shared in order; first hit
   wins. Ids are unique across mailboxes (§9.3), so "own first" only matters
   for the artificial duplicate case.
8. **Thread safety.** Tool calls, sync and the tray use one instance from
   different threads. Guard the key→index map and ordered key list with one
   `System.Threading.Lock`. Never hold the lock while querying SQLite or
   deleting files. A search racing a `Remove` may throw from SQLite; that is
   acceptable and not handled.
9. **Disable / Remove** call `EmailIndex.Close()` before dropping the
   instance; `Remove(..., deleteFile: true)` deletes the three files after
   `Close()`. A later `Add` of the same mailbox opens a fresh `EmailIndex`
   on the same path (keeping old data when the file was kept).
10. No logging, no `ActivityHub` calls, no settings writes here. The caller
    updates `Settings` (`AddOrEnableSharedMailbox` / `DisableSharedMailbox`)
    separately.

## Spec changes (proposed)

Append to SPEC §9.3, after the `Add`/`Disable`/`Remove` bullet:

> - Mailbox arguments are trimmed and lower-cased; empty means the own
>   mailbox. Unknown or disabled mailboxes give
>   `Mailbox "<input>" is not configured or not enabled. Available mailboxes: "" (your own mailbox), "<smtp>", …. To use another shared mailbox, ask the user to enable it in the Clippy tray menu under Shared mailboxes.`
>   `all` outside search gives
>   `Mailbox "all" only works with search tools. Use one mailbox: <list>.`
> - The `all` merge sorts newest first; ties go own mailbox first, then
>   shared mailboxes in the order they were added. `limit`/`offset` apply
>   after the merge; the 200 cap is applied by the tool.
> - `Locate` returns nothing when no enabled index has the id (the tool then
>   falls back to COM, §11.2).
> - `Disable` closes the index and keeps the file. `Remove(mailbox, deleteFile)`
>   also works on a disabled mailbox and deletes the `.db`, `-wal` and `-shm`
>   files. The own mailbox can't be disabled or removed here; rebuilding it
>   is `SyncService`'s job (§10).

Append to SPEC §18 "Decided":

> - Index (M2.4): Core references `ModelContextProtocol.Core` (same version
>   as the App's `ModelContextProtocol.AspNetCore`) so Core code can throw
>   `McpException` directly, as §9.3 and §11 require.
