# M11.5 `AnthropicApiModel`: the API-key backend

Base: `dev` after M11.4 (`ede2804`). This task implements the
`IDraftModel` contract that M11.4 pinned in
`src/ClippysRevenge.Core/DraftModel.cs`, and reuses the `internal`
helpers in `ClaudeCli.cs` (`ClaudeCliArgs.IsValidModel`, `IsValidEffort`,
`TryCompactSchema`) and `ClaudeCliRunner.MaxPromptBytes`. Don't change
`DraftModel.cs` or `ClaudeCli.cs`.

## Goal

Add the optional second backend for AI drafting (SPEC §19.3, "API-key
backend"). It makes one non-streaming Messages API call per request using
the official Anthropic C# SDK and the API key the user saved (§19.2,
§5.1, M11.1 `SettingsStore.LoadApiKey`). The call carries `model`,
`max_tokens`, `system`, one user message and
`output_config = { effort, format = { type: "json_schema", schema } }`. It
has no `thinking` and no tools (§19.5). HTTP and SDK outcomes map onto
M11.4's `ModelResult`. `CheckAsync` reads `GET /v1/models/<model>`, which
uses no tokens, and returns one of the five §19.3 status texts.

SPEC refs: §1.10, §3 (`AnthropicApiModel.cs`), §5.1, §19.2, §19.3,
§19.5, §19.7 (how the worker uses `RateLimited`/`NotSignedIn`), §19.11,
§19.12, §15.

Nothing is wired into `Program` or the UI here. Picking the backend is
M11.7 and the key box plus Check button are M11.8.

## SDK facts this brief relies on (verified 2026-11-13)

Checked against the source at tag `Anthropic-v13.3.0` of
`anthropics/anthropic-sdk-csharp`, the package's XML docs, and a
throwaway console probe built against the package with a fake
`HttpMessageHandler`:

- **Package:** NuGet `Anthropic`, pin **`13.3.0`** (published
  2026-10-23, 3 weeks old; 13.4–13.8 are less than 2 weeks old). Its
  TFMs are `net8.0`, `net9.0` and `netstandard2.0`. It is fully managed
  and has no Windows dependencies. Its dependencies are
  `Microsoft.Extensions.AI.Abstractions >= 10.5.1`,
  `System.Net.ServerSentEvents >= 10.0.1` and `System.Text.Json >= 10.0.6`.
  `ModelContextProtocol.Core` 2.4.0 already pulls
  `Microsoft.Extensions.AI.Abstractions` 10.11.0, so restoring both
  causes no downgrade (the probe built with `TreatWarningsAsErrors`).
  Versions 3.x and below of the package were the unrelated tryAGI SDK;
  10+ is official. **The package goes into `ClippysRevenge.Core`.**
- `new AnthropicClient(ClientOptions)`. `ClientOptions` is a
  `record struct` with settable `ApiKey`, `HttpClient`,
  `IReadOnlyList<DelegatingHandler> Handlers`, `string BaseUrl`,
  `int? MaxRetries`, `TimeSpan? Timeout` and
  `OpenTelemetryOptions? OpenTelemetry` (implicit from `bool`). The
  client is `IDisposable`, and disposing it disposes its `HttpClient`
  and handlers.
- **Auth header:** the SDK sends `ApiKey` as
  **`Authorization: Bearer <key>`** and never as `x-api-key`
  (`ParamsBase.AddDefaultHeaders`; SDK tests assert
  `!Headers.Contains("X-Api-Key")`). It sends
  `anthropic-version: 2026-10-21`. The platform docs (API overview,
  Authentication) list `Authorization: Bearer <API key>` as the primary
  header and `x-api-key` as a "legacy fallback". **The tests assert the
  Bearer header and the absence of `x-api-key`**, which is what the
  pinned SDK sends. See "Spec changes" #2.
- **Environment fallbacks the SDK has and this code must defeat:**
  `BaseUrl` defaults to `ANTHROPIC_BASE_URL`. When no credential option
  is set, the credential comes from `ANTHROPIC_API_KEY` /
  `ANTHROPIC_AUTH_TOKEN` or profile files (`AnthropicCredentials.Resolve`).
  Tracing comes from `ANTHROPIC_OPEN_TELEMETRY*`, and its content mode
  can record prompts. Setting `ApiKey` (non-null), `BaseUrl` and
  `OpenTelemetry = false` explicitly turns all three off. The probe
  confirmed that requests went to `https://api.anthropic.com` with
  `ANTHROPIC_BASE_URL` set elsewhere.
- **Retries:** by default the SDK retries 408/409/429/5xx and
  connection errors twice, and it sleeps for whatever `retry-after`
  says, with no cap. `MaxRetries = 0` sends exactly one attempt; the
  probe confirmed one handler call per request for 401–529.
- **Errors:** a non-2xx response throws `AnthropicApiException`
  (`HttpStatusCode StatusCode`, `string ResponseBody`). Its subclasses
  are `AnthropicUnauthorizedException` (401), `AnthropicForbiddenException`
  (403), `AnthropicNotFoundException` (404), `AnthropicRateLimitException`
  (429) and `Anthropic5xxException` (500–599, including 529).
  **`AnthropicApiException.Message` includes the response body**, so
  never log or surface it. Network failures throw `AnthropicIOException`.
  Caller cancellation throws `TaskCanceledException`. A 200 response
  whose body isn't JSON throws `System.Text.Json.JsonException`, and a
  200 response of `{}` throws `AnthropicInvalidDataException` when
  `Content` is read. **Exceptions carry no response headers**, so
  `retry-after` is captured by a per-call `DelegatingHandler` (see
  Behavior §C).
- **Request types** (namespace `Anthropic.Models.Messages`):
  `MessageCreateParams { required long MaxTokens; required IReadOnlyList<MessageParam> Messages; required ApiEnum<string, Model> Model; MessageCreateParamsSystem? System; OutputConfig? OutputConfig; … }`.
  `string` converts implicitly to `ApiEnum<string, Model>`,
  `MessageCreateParamsSystem` and `MessageContentParam`.
  `new UserMessageParam(string)` converts implicitly to `MessageParam`.
  `OutputConfig { ApiEnum<string, Effort>? Effort; JsonOutputFormat? Format; }`
  (`"medium"` converts implicitly). `JsonOutputFormat { required IReadOnlyDictionary<string, JsonElement> Schema; }`
  sets `type: "json_schema"` itself. **The SDK can express
  `output_config` natively, so no raw/extra-body escape hatch is
  needed.** Properties left unset (`Thinking`, `Tools`, `ToolChoice`,
  `Temperature`, `Metadata`, …) are absent from the body. The probe's
  captured body was exactly:
  `{"model":"claude-opus-5-5","max_tokens":8000,"system":"SYS","messages":[{"role":"user","content":"hello"}],"output_config":{"effort":"medium","format":{"type":"json_schema","schema":{…}}}}`.
- **Response:** `Message.Content` (`IReadOnlyList<ContentBlock>`;
  `block.TryPickText(out TextBlock t)` gives `t.Text`),
  `Message.StopReason` (`ApiEnum<string, StopReason>?`; `.Raw()` gives
  the wire string, such as `end_turn`, `max_tokens` or `refusal`), and
  `Message.Usage.InputTokens` / `OutputTokens` (`long`).
- **Models endpoint:**
  `client.WithRawResponse.Models.Retrieve(string modelID, ModelRetrieveParams? parameters = null, CancellationToken cancellationToken = default)`
  sends `GET {BaseUrl}/v1/models/{id}` and returns a disposable
  `HttpResponse<ModelInfo>`. Use the raw variant and don't deserialize,
  because only the status matters.
- **Structured-outputs schema limits** (platform docs, structured
  outputs, "JSON Schema limitations"): `minimum`, `maximum`,
  `multipleOf`, `minLength`, `maxLength` and array constraints other
  than `minItems` 0/1 are **not supported, and a raw schema that uses
  them gets HTTP 400**. `DraftModel.ReplySchema` has `minimum`, `maximum`
  and `maxLength`, so the schema must be reduced before it is sent
  (Behavior §B, "Spec changes" #4). Local validation
  (`DraftReply.Parse`) already enforces those bounds.

## Hard rules that apply here

- **Only the user's saved key.** The key comes only from the injected
  `loadApiKey` delegate (the App passes `SettingsStore.LoadApiKey`).
  Never set `AuthToken` or `Credentials`, never call
  `AnthropicCredentials`, and never read `ANTHROPIC_*` environment
  variables yourself. When there is no usable key, **no HTTP request is
  made**, so the SDK's environment and profile fallbacks can never run.
  No Claude Code credential is involved (§1.10).
- **Never log or surface the key.** Don't log it, put it in an exception
  message or in `ModelStatus.Text`, or keep it in a field. Read it per
  call (§19.3: "read from DPAPI storage per call") and let it go out of
  scope. Never log `ex`, `ex.Message`, `ResponseBody`, `ToString()` of
  SDK params or responses, prompts, or model output (§19.11).
- **The model gets no tools** (§19.5): no `Tools`, `ToolChoice`,
  `Thinking`, `Container` or MCP servers in the request. Everything else
  stays unset as well.
- **Only `api.anthropic.com`:** `BaseUrl = "https://api.anthropic.com"`
  is set explicitly on every client.
- A file named `Anthropic*` has no `.Send(`, `.Display(`, `.Move(` or
  `Delete(` (§19.12). `base.SendAsync(` in a `DelegatingHandler` is
  fine, because the scan matches `\.\s*Send\s*\(`.

## Public API

```csharp
namespace ClippysRevenge.Core;

/// <summary>The optional IDraftModel over the official Anthropic C# SDK (SPEC 19.3). Thread-safe.</summary>
public sealed class AnthropicApiModel : IDraftModel, IDisposable
{
    public const string ApiBaseUrl = "https://api.anthropic.com";
    /// <summary>Whole-check bound for GET /v1/models/{model}.</summary>
    public static readonly TimeSpan CheckTimeout = TimeSpan.FromSeconds(15);
    /// <summary>Added to our own deadline for the SDK's per-attempt timeout, so ours always fires first.</summary>
    public static readonly TimeSpan SdkTimeoutSlack = TimeSpan.FromSeconds(60);
    public const int MaxOutputTokensLimit = 32_000;
    /// <summary>RetryAt beyond now + this is dropped (null).</summary>
    public static readonly TimeSpan MaxRetryAfter = TimeSpan.FromDays(8);

    /// <param name="settings">Read by CheckAsync for Model only. RunAsync uses request.Model/Effort.</param>
    /// <param name="loadApiKey">Called once per RunAsync/CheckAsync; App passes SettingsStore.LoadApiKey.
    /// Null, a throw, or a value failing SettingsStore.IsValidApiKeyFormat all mean "no key".</param>
    /// <param name="handler">Innermost HTTP handler (tests pass a fake). Null = an owned SocketsHttpHandler.
    /// A passed handler is never disposed by this class.</param>
    /// <exception cref="ArgumentNullException">settings or loadApiKey is null.</exception>
    public AnthropicApiModel(Func<AiDraftingSettings> settings, Func<string?> loadApiKey,
        HttpMessageHandler? handler = null, TimeProvider? time = null, ILogger? logger = null);

    /// <summary>Never throws except OperationCanceledException when ct is cancelled. Uses no tokens.</summary>
    public Task<ModelStatus> CheckAsync(CancellationToken ct);

    /// <summary>Never throws (ArgumentNullException for a null request aside).</summary>
    public Task<ModelResult> RunAsync(ModelRequest request, CancellationToken ct);

    /// <summary>Disposes the owned SocketsHttpHandler, if any. Idempotent.</summary>
    public void Dispose();
}

public static class AnthropicApiStatusTexts
{
    public const string NoKey = "✗ No API key saved.";
    public const string NoAnswer = "✗ api.anthropic.com didn't answer.";
    public static string Ready(string model);            // ✓ API key works (<model>)
    public static string Rejected(int httpStatus);       // ✗ The API key was rejected (HTTP <code>).
    public static string ModelUnavailable(string model); // ✗ The model "<model>" isn't available with this key.
}

/// <summary>Reduces a JSON schema to what structured outputs accept (SPEC 19.3). Pure.</summary>
public static class AnthropicWireSchema
{
    /// <summary>Keywords removed from every schema object (see Behavior B).</summary>
    public static IReadOnlyList<string> DroppedKeywords { get; }

    /// <summary>False when jsonSchema isn't a JSON object. Never throws.
    /// The dictionary is the reduced root object's members (values Clone()d), in document order.</summary>
    public static bool TryReduce(string? jsonSchema, out IReadOnlyDictionary<string, JsonElement> schema);
}
```

## Behavior

### A. Per-call client

Every `RunAsync` and every `CheckAsync` that reaches the network builds
a fresh client from the key it just loaded, and disposes it at the end:

```csharp
var capture = new RetryAfterCapture();                       // private nested DelegatingHandler
using var client = new AnthropicClient(new ClientOptions
{
    ApiKey = key,                                            // never null here
    HttpClient = new HttpClient(_handler, disposeHandler: false) { Timeout = Timeout.InfiniteTimeSpan },
    Handlers = [capture],
    BaseUrl = ApiBaseUrl,
    MaxRetries = 0,
    Timeout = deadline + SdkTimeoutSlack,                    // deadline = request.Timeout or CheckTimeout
    OpenTelemetry = false,
});
```

- Disposing the client disposes `capture` and the per-call `HttpClient`
  but **not** `_handler`, because of `disposeHandler: false`. The probe
  confirmed this. The shared handler keeps connection pooling.
- The owned default handler is
  `new SocketsHttpHandler { AutomaticDecompression = DecompressionMethods.All, PooledConnectionLifetime = TimeSpan.FromMinutes(5), UseCookies = false }`.
  The system proxy settings are left at their defaults.
- `ClientOptions`' field initializer also creates an unused default
  `HttpClient` per instance. That object holds no sockets and is left
  to the GC. This is accepted; don't work around it.
- **Our deadline:** `using var deadlineCts = new CancellationTokenSource(deadline, _time)`,
  linked with `ct`. Pass the linked token to the SDK. The SDK's own
  per-attempt timeout runs on the real clock with `SdkTimeoutSlack`
  added, so in practice ours fires first. If the SDK's fires anyway (a
  `TaskCanceledException` while `ct` isn't cancelled), it is treated as
  a timeout too.

### B. `AnthropicWireSchema.TryReduce`

1. Parse with `JsonDocument`. If the root isn't an object, or it doesn't
   parse, return false. Reuse `ClaudeCliArgs.TryCompactSchema` for the
   "is a JSON object" check, or parse directly; either is fine.
2. Rewrite the tree into a new compact JSON document with
   `Utf8JsonWriter`, keeping member order. Then return the root's
   members as a dictionary with `Clone()`d values. Use a
   `Dictionary<string, JsonElement>` built in document order, then
   `AsReadOnly()`. The SDK freezes it, and wire order doesn't matter.
3. **Schema objects:** the root, each value inside `properties`,
   `patternProperties`, `$defs` and `definitions` (these four are
   name → schema maps, so their member *names* are never dropped), the
   value of `items`, `additionalItems`, `not`, `if`, `then`, `else` and
   `contains` when it is an object, and each object element of `anyOf`,
   `allOf`, `oneOf` and `prefixItems`. In a schema object:
   - drop the members named in `DroppedKeywords`: `minimum`, `maximum`,
     `exclusiveMinimum`, `exclusiveMaximum`, `multipleOf`, `minLength`,
     `maxLength` and `maxItems`;
   - drop `minItems` when its value is a number greater than 1;
   - copy everything else unchanged (`type`, `required`, `enum`,
     `const`, `default`, `description`, `additionalProperties`,
     `format`, `pattern`, …). Don't recurse into `default`, `const`,
     `enum` or `examples`, because those are data, not schemas.
4. Never throws: catch `JsonException` and return false.

`DraftModel.ReplySchema` reduces to exactly:
`{"type":"object","additionalProperties":false,"required":["needs_reply","confidence","reason"],"properties":{"needs_reply":{"type":"boolean"},"confidence":{"type":"number"},"reply_all":{"type":"boolean"},"body_html":{"type":"string"},"reason":{"type":"string"}}}`.
`DraftModel.StyleSchema` comes out unchanged.

### C. `RetryAfterCapture` (private nested `DelegatingHandler`)

`SendAsync`: `var resp = await base.SendAsync(request, ct)`, then
record `resp.Headers.RetryAfter?.Delta` and `?.Date` into two fields and
return `resp`. It reads nothing else and logs nothing. One instance per
call, so there is no shared state.

`RetryAt` once the call has failed with 429 or 529, using
`now = _time.GetUtcNow()`:
- `Delta` is set and `> 0` → `now + Delta`;
- else `Date` is set and is after `now` → `Date`;
- else null.

If the result is later than `now + MaxRetryAfter`, return null.
`retry-after-ms` and the `anthropic-ratelimit-*` headers are ignored.

### D. `RunAsync(request, ct)`

1. `ArgumentNullException.ThrowIfNull(request)`.
2. **Input checks.** Each of these gives `Failed(BadInput, null)` with
   **no** key load and **no** HTTP call:
   - `Timeout <= TimeSpan.Zero`;
   - `SystemPrompt` is null;
   - `UserPrompt` is null or empty;
   - `Encoding.UTF8.GetByteCount(UserPrompt) > ClaudeCliRunner.MaxPromptBytes`;
   - `!ClaudeCliArgs.IsValidModel(Model)` or `!ClaudeCliArgs.IsValidEffort(Effort)`;
   - `MaxOutputTokens` is not within `1..MaxOutputTokensLimit`;
   - `!AnthropicWireSchema.TryReduce(JsonSchema, out var schema)`.
3. If `ct.IsCancellationRequested` → `Failed(Cancelled, null)`, with no
   key load.
4. **Key:** `key = SafeLoadKey()`. This calls `loadApiKey()`, trims the
   result, and returns null when the delegate throws (any exception),
   returns null or blank, or the key fails
   `SettingsStore.IsValidApiKeyFormat`. A null key → `NotSignedIn`, with
   **no HTTP call**.
5. **Request:**
   ```csharp
   new Sdk.MessageCreateParams
   {
       Model = request.Model,
       MaxTokens = request.MaxOutputTokens,
       System = request.SystemPrompt,            // omit (leave unset) when SystemPrompt is whitespace-only
       Messages = [new Sdk.UserMessageParam(request.UserPrompt)],
       OutputConfig = new Sdk.OutputConfig
       {
           Effort = request.Effort,
           Format = new Sdk.JsonOutputFormat { Schema = schema },
       },
   }
   ```
   Set nothing else.
6. `start = _time.GetTimestamp()`, then
   `var msg = await client.Messages.Create(p, linked.Token)`. Read
   `Content`, `StopReason` and `Usage` inside the same `try`, because
   the SDK deserializes lazily and a malformed body throws when it is
   read. Set `duration = _time.GetElapsedTime(start)`, measured when the
   response has been read or the call has failed.
7. **Success mapping** (status 2xx):
   - `stop = msg.StopReason?.Raw()`.
   - `text` = the concatenation of `t.Text` over every block where
     `TryPickText(out t)`. Thinking and other blocks are skipped.
   - `stop == "refusal"` → `Failed(NoStructuredOutput, null)`.
   - `stop == "max_tokens"` → `Failed(BadOutput, null)`.
   - `text.Trim()` parses (`JsonDocument`) as a JSON **object** →
     `Ok(root.Clone(), duration, Tok(in), Tok(out))`.
   - Otherwise (no text block, empty text, non-JSON, array or scalar) →
     `Failed(NoStructuredOutput, null)`.
   - `Tok(long v)` = `v is >= 0 and <= int.MaxValue ? (int)v : null`.
     Reading `Usage` throwing → both tokens null; the result is still
     `Ok`.
8. **Failure mapping**, in this order:

   | Caught | Result |
   |---|---|
   | `AnthropicApiException e` with `(int)e.StatusCode` 401 or 403 | `NotSignedIn` |
   | the same, with 429 or 529 | `RateLimited(RetryAt)` (§C) |
   | the same, any other status | `Failed(Http, (int)e.StatusCode)` |
   | `OperationCanceledException` and `ct.IsCancellationRequested` | `Failed(Cancelled, null)` |
   | `OperationCanceledException` otherwise (our deadline or the SDK's timeout) | `Failed(Timeout, null)` |
   | `AnthropicIOException` or `HttpRequestException` | `Failed(Http, null)` |
   | `JsonException` or `AnthropicInvalidDataException` | `Failed(BadOutput, null)` |
   | any other `Exception` | `Failed(Http, null)` |

   Never rethrow, and never read `e.Message` or `e.ResponseBody`.
9. **Log** at Information, once per call:
   `"Anthropic API call: {ResultKind} in {Ms} ms, tokens {In}/{Out}, HTTP {Status}"`.
   `ResultKind` uses the same spelling as `ClaudeCliModel` (`Ok`,
   `RateLimited`, `NotSignedIn`, `Failed:<ModelFailure>`). `Status` is
   the HTTP status when known (200 for `Ok`, the exception's status for
   API errors), else null. Don't log the key, model, prompts, output,
   response body or exception.
10. `settings()` isn't called in `RunAsync`.

### E. `CheckAsync(ct)`

1. `ct.ThrowIfCancellationRequested()`.
2. `model = settings().Model`. If `!ClaudeCliArgs.IsValidModel(model)`
   → `(false, ModelUnavailable(model))`, with no key load and no HTTP
   call. Settings validation normally prevents this.
3. `key = SafeLoadKey()`. Null → `(false, NoKey)`, with no HTTP call.
4. Per-call client (§A) with deadline `CheckTimeout`.
   `using var resp = await client.WithRawResponse.Models.Retrieve(model, cancellationToken: linked.Token)`.
   Don't deserialize.

   | Outcome | Status |
   |---|---|
   | returned (2xx) | `(true, Ready(model))` |
   | `AnthropicApiException` 401 or 403 | `(false, Rejected(status))` |
   | `AnthropicApiException` 400 or 404 | `(false, ModelUnavailable(model))` |
   | any other `AnthropicApiException` (429, 5xx, …) | `(false, NoAnswer)` |
   | `OperationCanceledException` and `ct.IsCancellationRequested` | **throw** `OperationCanceledException(ct)` (interface contract) |
   | `OperationCanceledException` otherwise (15 s deadline) | `(false, NoAnswer)` |
   | `AnthropicIOException`, `HttpRequestException` or any other exception | `(false, NoAnswer)` |

5. No caching: each call is one GET. The worker and the UI decide how
   often to call it.
6. Log at Information:
   `"Anthropic API status: {Kind}, HTTP {Status}"`, where `Kind` is
   `Ready`, `NoKey`, `Rejected`, `ModelUnavailable` or `NoAnswer`.
   Don't log the model name or the key.

### F. `SettingsStore.IsValidApiKeyFormat(key)`

Returns `key.Length is >= 1 and <= MaxApiKeyLength` and no char is
`char.IsWhiteSpace` or `char.IsControl`. `SaveApiKey` keeps its two
distinct messages: it checks empty first, then calls this for the
"single line without spaces" message. A null argument →
`ArgumentNullException`.

## Spec changes (proposed, not applied)

All are low-risk and reversible, and none weakens a hard rule. #2–#4
are needed for the backend to work at all with the pinned SDK and the
current API.

1. **§19.3 / §3 SDK pin.** NuGet `Anthropic` **13.3.0** (official
   package since 10.x; 3.x and below were tryAGI's). Managed only
   (`net8.0` / `netstandard2.0`), referenced from
   `ClippysRevenge.Core`. The file is `AnthropicApiModel.cs`, as §3
   already says.
2. **§19.3 Auth header.** The SDK (API version `2026-10-21`) sends the
   key as `Authorization: Bearer <key>`. `x-api-key` (documented as a
   legacy fallback) is not sent. Log redaction (§5) already masks
   `Bearer <anything>`.
3. **§19.3 Client settings.** Base URL fixed to
   `https://api.anthropic.com` (`ANTHROPIC_BASE_URL` is ignored). SDK
   retries off (`MaxRetries = 0`); backoff is `DraftWorker`'s (§19.7).
   SDK OpenTelemetry off. The key is always passed explicitly, so the
   SDK never resolves a credential from `ANTHROPIC_API_KEY`,
   `ANTHROPIC_AUTH_TOKEN` or profile files. With no saved key, no
   request is made: `RunAsync` → `NotSignedIn`, `CheckAsync` →
   `✗ No API key saved.` A saved key that can't be read or fails the
   save rule counts as no key. A client is built per call (the key is
   read per call).
4. **§19.3 Wire schema.** Before sending, the schema drops the keywords
   structured outputs reject with HTTP 400 (`minimum`, `maximum`,
   `exclusiveMinimum`, `exclusiveMaximum`, `multipleOf`, `minLength`,
   `maxLength`, `maxItems`, and `minItems` > 1). `DraftReply.Parse`
   (§19.7) still enforces them locally. The CLI backend keeps the full
   schema.
5. **§19.3 Output mapping.** The output is the concatenation of the
   response's `text` blocks (thinking blocks skipped).
   `stop_reason: refusal` → `NoStructuredOutput`. `max_tokens` →
   `BadOutput`. Text that isn't a JSON object → `NoStructuredOutput`. A
   2xx body the SDK can't read → `BadOutput`. A network error →
   `Failed(Http, null)`. `TimeoutSeconds` expiring → `Timeout`.
   Cancellation → `Cancelled`. Token counts that don't fit an `int` →
   null.
6. **§19.3 `retry-after`.** Either delta-seconds or an HTTP-date. Kept
   only when in the future and at most 8 days ahead, else null.
   `retry-after-ms` and `anthropic-ratelimit-*` are ignored.
7. **§19.3 Check mapping.** 2xx → ready. 401/403 → rejected. 400/404 →
   model not available. Anything else (429, 5xx, network, the 15 s
   bound) → `✗ api.anthropic.com didn't answer.` Not cached: each Check
   is one GET.
8. **§19.3 Input limits (API backend).** The user prompt has the same
   2 MiB cap as the CLI (`BadInput`). `MaxOutputTokens` must be within
   1–32,000. A whitespace-only system prompt is omitted from the
   request.
