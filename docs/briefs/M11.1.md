# M11.1 AI drafting: settings and plumbing

## Goal

Lay the groundwork that every later M11 task builds on, with no model
calls, COM or UI yet (SPEC §19.2, §5.1, §5.2, §19.4, §6.1, §6.4, §7,
§19.11, §19.12):

- `AiDraftingSettings` (Core) as `Settings.AiDrafting`, with the §19.2
  defaults, bounds, the consent rule, and JSON that follows the §5.2 rules.
  It also gets two small helpers that the UI (M11.8) and the worker (M11.7)
  share: `SetEnabled`/`RecordConsent` and `CandidateCutoff`. A
  `SenderPattern` type parses and matches the `ExcludeSenders` and
  `IncludeOnlySenders` entries.
- `SharedMailbox.AiDrafts` (§5.2).
- `SettingsStore.LoadApiKey` and `SaveApiKey`, which keep the Anthropic API
  key in `anthropic-key.bin` through `ISecretProtector`, the same way as
  the token (§5.1, §19.2).
- Log redaction of the saved API key and of anything matching
  `sk-ant-[A-Za-z0-9_-]+` (§5.1).
- `DraftMarker` constants (§19.4).
- `ActivityState.Drafting`: its rank, tray tooltip, Activity header and a
  state-targeted `Report`. Plus `ActivityKind.Ai` (§6.1, §6.4, §7).

## Hard rules that apply here

- **The API key never reaches `settings.json`, a log, an exception
  message, an activity event or `ToString()`.** The API-key exceptions
  below use fixed texts that never include the input.
- **No Claude credentials.** Nothing here reads Claude Code's files or any
  environment variable (§1.10, §19.5). No string literal in `src/` may
  contain `.credentials`, `claudeAiOauth`, `oauthAccount` or `sk-ant-oat`.
  The M11.9 scan checks this. The redaction regex `sk-ant-[A-Za-z0-9_-]+`
  is allowed.
- Nothing here sends mail or touches COM.

## Public API

### `AiSettings.cs`

```csharp
namespace ClippysRevenge.Core;

public enum AiBackend { ClaudeCode, ApiKey }

/// <summary>SPEC 19.2. Mutable settings data; deep-copied with Settings.Clone/CopyFrom.</summary>
public sealed class AiDraftingSettings
{
    public const string DefaultModel = "claude-opus-5-5";
    public const string DefaultEffort = "medium";
    public static IReadOnlyList<string> Efforts { get; } = ["low", "medium", "high", "xhigh", "max"];
    public const int MaxModelLength = 64;
    public const int DefaultDailyCap = 30, MinDailyCap = 1, MaxDailyCap = 500;
    public const double DefaultMinConfidence = 0.6;
    public const int DefaultMaxAgeDays = 2, MinMaxAgeDays = 1, MaxMaxAgeDays = 14;
    public const int DefaultTimeoutSeconds = 180, MinTimeoutSeconds = 30, MaxTimeoutSeconds = 900;
    public const int MaxSenderEntries = 200;
    public const string FieldPrefix = "AiDrafting";

    public const string ConsentRequiredMessage =
        "Turn on AI drafts from the tray or Settings so Clippy can ask for your consent first.";

    public bool Enabled { get; set; }
    public DateTimeOffset? ConsentedAtUtc { get; set; }
    public DateTimeOffset? EnabledAtUtc { get; set; }
    public AiBackend Backend { get; set; } = AiBackend.ClaudeCode;
    public string Model { get; set; } = DefaultModel;
    public string Effort { get; set; } = DefaultEffort;
    public int DailyCap { get; set; } = DefaultDailyCap;
    public double MinConfidence { get; set; } = DefaultMinConfidence;
    public int MaxAgeDays { get; set; } = DefaultMaxAgeDays;
    public bool RequireDirectRecipient { get; set; } = true;
    public List<string> ExcludeSenders { get; set; } = [];
    public List<string> IncludeOnlySenders { get; set; } = [];
    public int TimeoutSeconds { get; set; } = DefaultTimeoutSeconds;
    public string ClaudeCliPath { get; set; } = "";
    public bool AutoRegenerateStyle { get; set; } = true;

    [JsonIgnore] public bool HasConsent => ConsentedAtUtc is not null;

    /// <summary>Sets ConsentedAtUtc to nowUtc (converted to UTC) when it is null. Never changes or clears an existing value.</summary>
    public void RecordConsent(DateTimeOffset nowUtc);

    /// <summary>
    /// The one way UI code turns automatic drafting on or off. Turning it on (false → true) sets
    /// EnabledAtUtc = nowUtc (UTC). true → true and turning it off leave EnabledAtUtc unchanged.
    /// </summary>
    /// <exception cref="InvalidOperationException">enabled is true and HasConsent is false. Message = ConsentRequiredMessage. Nothing is changed.</exception>
    public void SetEnabled(bool enabled, DateTimeOffset nowUtc);

    /// <summary>
    /// The oldest receive time a candidate may have (SPEC 19.7): max(nowUtc − MaxAgeDays, EnabledAtUtc ?? nowUtc).
    /// A null EnabledAtUtc gives nowUtc, so no existing mail qualifies. Result is UTC.
    /// </summary>
    public DateTimeOffset CandidateCutoff(DateTimeOffset nowUtc);

    /// <summary>Errors with fields "AiDrafting.&lt;Name&gt;", in the order of SPEC 19.2's table. Never throws, never mutates.</summary>
    public IReadOnlyList<SettingsError> Validate();

    /// <summary>After deserialization: null Model/Effort → defaults, null lists → [], null ClaudeCliPath → "". Null list entries stay (Validate reports them).</summary>
    internal void FillDefaults();
}

/// <summary>One ExcludeSenders / IncludeOnlySenders entry: an address, or a domain that also matches its subdomains (SPEC 19.2, 19.7).</summary>
public readonly record struct SenderPattern(string Value, bool IsDomain)
{
    public const int MaxDomainLength = 253;

    /// <summary>
    /// Trims the entry. "@domain" or a string without '@' → domain. A string containing '@' (not at index 0)
    /// → address, valid per EmailAddress.IsValid. Value is lower-case (invariant). False for null/blank/invalid.
    /// </summary>
    public static bool TryParse(string? entry, out SenderPattern pattern);

    /// <summary>
    /// address is trimmed and lower-cased. An address pattern matches the same address exactly. A domain pattern
    /// matches when the part after the last '@' equals Value or ends with "." + Value. False for null, blank or a
    /// string without '@'.
    /// </summary>
    public bool Matches(string? address);
}
```

`DraftRules` (M11.7) must use `SenderPattern` for the `excluded` and
`not_included` rules. It must not write its own parser.

## Behavior

### A. `AiDraftingSettings.Validate()`

Field names are `AiDrafting.<Property>`, and list entries are
`AiDrafting.<List>[i]`. Errors come in this order, and every applicable
error is returned:

| Field | Invalid when | Message |
|---|---|---|
| `AiDrafting.Enabled` | `Enabled && ConsentedAtUtc is null` | `ConsentRequiredMessage` (exact text from §19.2) |
| `AiDrafting.Backend` | `!Enum.IsDefined(Backend)` | `Must be ClaudeCode or ApiKey.` |
| `AiDrafting.Model` | null, length 0 or > 64, or not matching `^[A-Za-z][A-Za-z0-9._\[\]-]*\z` (use `\z`, not `$`, because `$` allows a trailing `\n`). Not trimmed | `Must be a model name like claude-opus-5-5: up to 64 letters, digits, '.', '_', '-', '[' or ']', starting with a letter.` |
| `AiDrafting.Effort` | not one of `Efforts` (ordinal, case-sensitive; null invalid) | `Must be low, medium, high, xhigh or max.` |
| `AiDrafting.DailyCap` | outside 1–500 | `Must be between 1 and 500.` |
| `AiDrafting.MinConfidence` | NaN, infinite, or outside 0.0–1.0 | `Must be between 0 and 1.` |
| `AiDrafting.MaxAgeDays` | outside 1–14 | `Must be between 1 and 14.` |
| `AiDrafting.ExcludeSenders` | list null | `Must not be empty.` |
| `AiDrafting.ExcludeSenders` | `Count > 200` | `At most 200 entries.` (entries are still checked) |
| `AiDrafting.ExcludeSenders[i]` | entry null or blank | `Must not be empty.` |
| `AiDrafting.ExcludeSenders[i]` | `!SenderPattern.TryParse(entry, out _)` | `Must be an email address or a domain like example.org.` |
| `AiDrafting.IncludeOnlySenders…` | same three rules as `ExcludeSenders` | same messages |
| `AiDrafting.TimeoutSeconds` | outside 30–900 | `Must be between 30 and 900.` |
| `AiDrafting.ClaudeCliPath` | see below | see below |

Duplicate sender entries are allowed, because they're harmless.

**`ClaudeCliPath`:** a null or empty value, or one that is only
whitespace, is valid (it means "find it"). Otherwise the trimmed value goes
through `Settings.PathError` (UNC and device paths are rejected, the path
must be fully qualified, and the existing messages are reused). If that
passes, the file extension (`Path.GetExtension`, case-insensitive) must be
`.exe` or `.js`. Otherwise:
`Must be the path of claude.exe or of Claude Code's cli.js.` This keeps
`.cmd`, `.bat` and `.ps1` out at the settings level too (§18, §19.3).

`ConsentedAtUtc` and `EnabledAtUtc` aren't validated.

### B. `Settings` integration

- `Settings.Validate()`: after the `SharedMailboxes` block, add
  `("AiDrafting", "Must not be empty.")` when `AiDrafting` is null.
  Otherwise append `AiDrafting.Validate()`. `SharedMailbox.AiDrafts` has
  no rule.
- `FromJson`: `s.AiDrafting ??= new AiDraftingSettings(); s.AiDrafting.FillDefaults();`.
  A missing `AiDrafts` stays `false`. An unknown `Backend` name throws
  `JsonException`, as other enums do. JSON property names are PascalCase,
  as declared. `JsonStringEnumConverter` already writes `"ClaudeCode"`.
  `DateTimeOffset?` uses the default ISO 8601 form.
- `CopyFrom`: `AiDrafting = c.AiDrafting;`. That is a new instance from the
  clone. The old instance is never mutated, because the worker may be
  reading it.
- `Clone` is unchanged. It works through JSON, so it's already deep.
- A `settings.json` with `Enabled: true` and no consent fails validation,
  so `Load()` renames it to `.bad` and restores defaults. That is the
  existing behavior for any invalid file, and it is intended.
- `AddOrEnableSharedMailbox`: new entries get `AiDrafts = false`.
  Re-enabling keeps the existing `AiDrafts` value. `DisableSharedMailbox`
  doesn't touch it.
- `SettingsEditor.Rebase`: add `AiDrafts = lm.AiDrafts` to the new-entry
  initializer. Rebase merging of `AiDrafting` itself is left to M11.8 (see
  Out of scope).

### C. `SetEnabled`, `RecordConsent`, `CandidateCutoff`

- Stored times are UTC: `nowUtc.ToUniversalTime()`.
- `RecordConsent` is idempotent. A second call with a later time doesn't
  change the value.
- `SetEnabled(true, …)` without consent throws, and `Enabled` and
  `EnabledAtUtc` stay as they were. `SetEnabled(false, …)` never throws.
- `CandidateCutoff(now)` = `max(now − MaxAgeDays days, EnabledAtUtc ?? now)`,
  in UTC. It uses `MaxAgeDays` as stored, without clamping.

### D. `SenderPattern`

- `TryParse`: trim. Null or blank gives false.
  - Starts with `@`: the rest must be a valid domain. → `(lower(rest), true)`.
  - Contains `@` elsewhere: must pass `EmailAddress.IsValid`. → `(lower, false)`.
  - No `@`: must be a valid domain. → `(lower, true)`.
- A valid domain is ASCII only, 1–253 characters, and has at least two
  labels separated by `.`. Each label is 1–63 characters of `[A-Za-z0-9-]`
  and doesn't start or end with `-`. That means no empty labels (`x..org`,
  `.x.org`, `x.org.`), no `*`, no `/` and no spaces.
- `Matches`: see the API comment. Comparisons are ordinal on lower-cased
  values. `a@badexample.org` does not match `example.org`.

### E. API key storage

- The file is `ApiKeyPath` in `DataDir`, written through
  `WriteAtomic(path, _protector.Protect(UTF8(key)))`, and
  `Directory.CreateDirectory(DataDir)` runs first.
- Validation runs before any file operation. No exception message, log or
  `ToString` contains the key.
- The format isn't checked (no `sk-ant-` prefix rule), because key formats
  may change.
- `CachedApiKey` is updated with `Volatile.Write` after a successful
  write, delete or load.

### F. Redaction

- `LogRedactor.Redact` masks every `sk-ant-[A-Za-z0-9_-]+` match with
  `[redacted]`, case-sensitive, wherever it appears in the line (message
  and exception text, because the provider redacts the whole line).
  `sk-ant-` with nothing after it is left alone.
- `Program.cs`:
  - Right after `var tokens = new TokenHolder(loaded.Token);`, call
    `store.LoadApiKey()` inside
    `try { … } catch (Exception ex) when (ex is IOException or UnauthorizedAccessException) { apiKeyUnreadable = true; }`.
  - Set `Secrets = () => [tokens.Current, store.CachedApiKey]`.
  - Once the logger exists, if `apiKeyUnreadable` is set, log the Warning
    `anthropic-key.bin could not be read.` with no exception object. The
    exception message could carry a path, but never the key. Keep it
    simple anyway.
  - The rest of the M11 code saves and removes keys through this same
    `store` instance, so `CachedApiKey` stays current.

### G. `Drafting` state and `Ai` kind

- Rank: between `Paused` and `Serving` (§6.1 table).
- `TrayPresenter.Update`, `case ActivityState.Drafting`:
  - The icon is `TrayIconKey.Busy` (the `Syncing` icon) and it isn't
    animated.
  - `text = label.Length == 0 ? ActivityHub.DraftingLabel : label`.
  - When `progress.Total > 0`, append
    `" (" + Done.ToString("N0", Invariant) + " / " + Total.ToString("N0", Invariant) + ")"`.
  - The tooltip and the status line are both `TrayText.Prefix + text`.
  - `ShowStartOutlook` is false. This falls out of the existing `Build`.
- `ActivityView.StateName(Drafting)` = `Drafting replies`. `Header` for
  `Drafting` ignores the label: `Drafting replies`, plus
  ` (<done> / <total>)` (N0, invariant) when `Total > 0`. There is no
  progress bar (`ShowProgress = false`), per §6.4.
- `ActivityKind.Ai` sits before `Error`, as listed in §6.4. `ActivityForm`
  already fills its filter from `Enum.GetValues<ActivityKind>()`, so it
  needs no change. `Row` keeps `Bold` for `Invite` only.
- `Report(state, done, total)`:
  - Checks its arguments first (`Idle`, an undefined state, or a negative
    `done`/`total` throw `ArgumentOutOfRangeException`).
  - Then, under the lock, picks the newest scope where
    `s.State == state`, sets its counts, and calls `MarkChanged`. It
    raises `Changed` exactly like the existing `Report`.
  - The existing parameterless `Report` keeps its target set
    (`Backfilling`/`Syncing`/`Purging`). Because drafting runs alongside
    sync, a sync `Report` must never land on a `Drafting` scope, and the
    reverse. See Spec changes.
- `StateBalloonPolicy`, `TrayIconArt` and the icons don't change.

## Spec changes (proposed)

The caller applies these to `SPEC.md`. This architect didn't edit it,
because other briefs are being written in parallel. All of them are
low-risk, reversible clarifications. None touches a hard rule or
user-visible behavior beyond §19.2's validation texts.

1. **§7, `Report`.** Replace the sentence about `Report(done, total)` with:
   "`Report(done, total)` updates the newest active `Backfilling`,
   `Syncing` or `Purging` scope and is a no-op when there is none, so a
   tool call or invite dialog never captures sync progress.
   `Report(state, done, total)` updates the newest active scope in exactly
   that state. The drafting worker uses `Report(Drafting, …)`, so sync and
   drafting, which can run at the same time, never update each other's
   counts." In §6.1, change "from `Report(done, total)`, which also
   updates the newest `Drafting` scope (§7)" to "from
   `Report(Drafting, done, total)` (§7)". Reason: with the old wording,
   whichever of a concurrent sync and drafting pass began last would
   receive both workers' counts.
2. **§19.2, validation details.**
   - Field names are `AiDrafting.<Field>`.
   - `Effort` is case-sensitive lower-case.
   - The `Model` pattern is anchored with `\z`.
   - `ExcludeSenders` and `IncludeOnlySenders` each allow at most 200
     entries (the cap now applies to both lists). A domain is ASCII, has
     at least two dot-separated labels, and each label is 1–63 characters
     of `[A-Za-z0-9-]` that don't start or end with `-`. Duplicates are
     allowed.
   - A non-empty `ClaudeCliPath` must also end in `.exe` or `.js`.
   - Messages: as in this brief's table A.
3. **§19.2, `EnabledAtUtc`.** It is set only through
   `AiDraftingSettings.SetEnabled`, which refuses to enable without
   consent. The candidate cutoff is
   `AiDraftingSettings.CandidateCutoff(now) = max(now − MaxAgeDays, EnabledAtUtc ?? now)`,
   so a hand-edited `Enabled: true` without `EnabledAtUtc` drafts nothing
   older than the current pass. That matches §18's "only mail received
   after AI drafts were turned on".
4. **§19.4.** `DraftMarker.Name = "ClippyDraft"`, and
   `DraftMarker.PropertyName` is the full DASL string.
   `DraftMarker.Normalize` maps `ai`/`tool` case-insensitively to the
   lower-case value. Anything else is null.
5. **§5.1, API key.**
   - `SettingsStore.LoadApiKey()` returns null for a missing, undecryptable
     or blank file, and throws on I/O errors.
   - `SaveApiKey` trims and rejects blank keys, keys over 512 characters,
     and keys with whitespace or control characters. Error texts never
     include the key.
   - `SettingsStore.CachedApiKey` (the last loaded or saved key) feeds log
     redaction. The app loads the key once at start-up for this.
6. **§6.4.** While `Drafting`, the Activity header reads
   `Drafting replies (<done> / <total>)`, with no progress bar.
7. **§3 layout:** `AiSettings.cs` also holds `SenderPattern`, the sender
   entry parser and matcher used by validation and `DraftRules`.
