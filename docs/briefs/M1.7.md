# M1.7 `Settings` model, defaults, `Validate()`, shared mailbox entries

## Goal

Add the settings model to Core (SPEC §3 `Settings.cs`, §5.2, §15 "Settings"
row). It holds every §5.2 setting with its default, the `SharedMailboxes`
entries from §5.2, a `Validate()` that returns per-field reasons for the
form (§5.2, §6.3), the "`AttachmentDir` is always allowed" rule, small
shared-mailbox helpers for the tray and Settings form (§6.2 check/uncheck),
and the JSON shape of `settings.json` (§5.1). That shape is plain
serialization, so it lives in Core, and M4.2 `SettingsStore` only adds file
I/O, DPAPI and the Run key. The auth token is **not** part of this model
(§5.1: "The token is never written to `settings.json`").

## Public API

```csharp
namespace ClippysRevenge.Core;

using System.Text.Json;
using Microsoft.Extensions.Logging;

/// <summary>One validation failure. Field is a property path, e.g. "Port",
/// "AllowedFolders[1]", "SharedMailboxes[0].Smtp". Message is a short
/// sentence shown next to the field.</summary>
public sealed record SettingsError(string Field, string Message);

public sealed class SharedMailbox
{
    public string Smtp { get; set; } = "";
    public string DisplayName { get; set; } = "";
    public bool Enabled { get; set; } = true;
    public List<string> IndexedFolders { get; set; } = [.. Settings.DefaultIndexedFolders];
    public int? RetentionMonths { get; set; }            // null = use the global value

    /// <summary>"Helpdesk <helpdesk@x.edu>", or just the Smtp when DisplayName is blank.</summary>
    [System.Text.Json.Serialization.JsonIgnore]
    public string MenuLabel { get; }

    public int EffectiveRetentionMonths(int globalRetentionMonths);
}

public sealed class Settings
{
    // Defaults and bounds (used by the form and by Validate)
    public const int DefaultPort = 8765;
    public const int MinPort = 1024, MaxPort = 65535;
    public const int DefaultRetentionMonths = 12;
    public const int MinRetentionMonths = 1, MaxRetentionMonths = 120;
    public const int DefaultSyncIntervalSeconds = 300;
    public const int MinSyncIntervalSeconds = 30, MaxSyncIntervalSeconds = 3600;
    public const int DefaultWorkStartHour = 8, DefaultWorkEndHour = 17;
    public const int DefaultInviteConfirmTimeoutSeconds = 120;
    public const int MinInviteConfirmTimeoutSeconds = 30, MaxInviteConfirmTimeoutSeconds = 900;
    public const int MaxTimeZoneLabelLength = 16;
    public const string AttachmentFolderName = "Clippy's Revenge";
    public static IReadOnlyList<string> DefaultIndexedFolders { get; } = ["Inbox", "Sent Items"];

    /// <summary>Defaults, with paths under Environment.SpecialFolder.UserProfile.</summary>
    public Settings();

    /// <summary>Defaults, with paths under the given profile directory (testable).</summary>
    public static Settings CreateDefault(string userProfileDir);

    public int Port { get; set; }
    public int RetentionMonths { get; set; }
    public int SyncIntervalSeconds { get; set; }
    public List<string> IndexedFolders { get; set; }
    public List<SharedMailbox> SharedMailboxes { get; set; }
    public int WorkStartHour { get; set; }
    public int WorkEndHour { get; set; }
    public bool BusinessDaysOnly { get; set; }
    public string TimeZoneLabel { get; set; }               // "" = derive from Windows
    public bool TentativeIsBusy { get; set; }
    public MeetingInviteMode MeetingInviteMode { get; set; }
    public int InviteConfirmTimeoutSeconds { get; set; }
    public string AttachmentDir { get; set; }
    public List<string> AllowedFolders { get; set; }
    public bool StartWithWindows { get; set; }
    public bool NotifyOnErrors { get; set; }
    public LogLevel LogLevel { get; set; }

    /// <summary>Empty list = valid. Never throws, never mutates.</summary>
    public IReadOnlyList<SettingsError> Validate();

    /// <summary>AttachmentDir first, then AllowedFolders, de-duplicated.</summary>
    public IReadOnlyList<string> EffectiveAllowedFolders();

    /// <summary>Case-insensitive, trimmed lookup by SMTP. Null when absent.</summary>
    public SharedMailbox? FindSharedMailbox(string smtp);

    /// <summary>Tray/Settings "check": add with defaults, or re-enable an existing entry.</summary>
    /// <exception cref="ArgumentException">smtp is not a valid address.</exception>
    public SharedMailbox AddOrEnableSharedMailbox(string smtp, string? displayName);

    /// <summary>Tray/Settings "uncheck": Enabled = false. False when not found.</summary>
    public bool DisableSharedMailbox(string smtp);

    /// <summary>Deep copy (new lists, new SharedMailbox instances).</summary>
    public Settings Clone();

    public string ToJson();

    /// <exception cref="JsonException">Malformed JSON or an unknown enum name.</exception>
    public static Settings FromJson(string json);
}
```

Keep all three types in `Settings.cs`. Don't add interfaces, options
classes or a separate validator type.

## Behavior

### Defaults (§5.2)

`CreateDefault(p)` (and `new Settings()` with `p =
Environment.GetFolderPath(Environment.SpecialFolder.UserProfile)`):

| Property | Default |
|---|---|
| `Port` | `8765` |
| `RetentionMonths` | `12` |
| `SyncIntervalSeconds` | `300` |
| `IndexedFolders` | new list `["Inbox", "Sent Items"]` |
| `SharedMailboxes` | new empty list |
| `WorkStartHour` / `WorkEndHour` | `8` / `17` |
| `BusinessDaysOnly` | `true` |
| `TimeZoneLabel` | `""` |
| `TentativeIsBusy` | `true` |
| `MeetingInviteMode` | `MeetingInviteMode.Send` |
| `InviteConfirmTimeoutSeconds` | `120` |
| `AttachmentDir` | `Path.Combine(p, "Downloads", "Clippy's Revenge")` |
| `AllowedFolders` | new list `[AttachmentDir, Path.Combine(p, "Documents")]` |
| `StartWithWindows` | `true` |
| `NotifyOnErrors` | `true` |
| `LogLevel` | `LogLevel.Information` |

Every instance gets its own list instances. Mutating one `Settings`' lists
must never affect another or `DefaultIndexedFolders`.

`IndexedFolders` entries are folder paths relative to the mailbox root,
`\`-separated (e.g. `Inbox\Projects`). This task only stores and validates
them. Resolving them to Outlook folders is M5/M6 (see Spec changes).

### `Validate()`

Check every rule and collect **all** errors in this order (fields in
declaration order, then shared mailboxes by index). It never throws, not
even on `null` lists or `null` list entries. Exact messages:

| Field | Rule | Message |
|---|---|---|
| `Port` | 1024–65535 | `Must be between 1024 and 65535.` |
| `RetentionMonths` | 1–120 | `Must be between 1 and 120.` |
| `SyncIntervalSeconds` | 30–3600 | `Must be between 30 and 3600.` |
| `IndexedFolders` | list null or empty | `Pick at least one folder.` |
| `IndexedFolders[i]` | null or whitespace | `Must not be empty.` |
| `IndexedFolders[i]` | equals an earlier entry (trimmed, OrdinalIgnoreCase) | `Listed twice.` |
| `WorkStartHour` | 0–23 | `Must be between 0 and 23.` |
| `WorkEndHour` | 1–24 | `Must be between 1 and 24.` |
| `WorkEndHour` | both in range and `WorkEndHour <= WorkStartHour` | `Must be later than the work start hour.` |
| `TimeZoneLabel` | null, or longer than 16 after trim, or contains a control char | `Must be empty or at most 16 printable characters.` |
| `MeetingInviteMode` | `!Enum.IsDefined` | `Must be Send, DraftOnly or Disabled.` |
| `InviteConfirmTimeoutSeconds` | 30–900 | `Must be between 30 and 900.` |
| `AttachmentDir` | path rule (below) | path message (below) |
| `AllowedFolders` | list null | `Must not be empty.` |
| `AllowedFolders[i]` | path rule | path message |
| `LogLevel` | `!Enum.IsDefined` | `Must be one of Trace, Debug, Information, Warning, Error, Critical, None.` |
| `SharedMailboxes` | list null | `Must not be empty.` |
| `SharedMailboxes[i]` | entry null | `Must not be empty.` |
| `SharedMailboxes[i].Smtp` | not a valid address (below) | `Must be an email address like name@example.org.` |
| `SharedMailboxes[i].Smtp` | same as an earlier entry (trimmed, OrdinalIgnoreCase) | `This mailbox is listed twice.` |
| `SharedMailboxes[i].IndexedFolders` / `[j]` | same three rules as `IndexedFolders` | same messages |
| `SharedMailboxes[i].RetentionMonths` | not null and outside 1–120 | `Must be between 1 and 120.` |

An empty `AllowedFolders` list is **valid**, because `AttachmentDir` is
always allowed. An empty `SharedMailboxes` list is valid. `DisplayName` is
not validated (null is treated as `""` by `MenuLabel`).

**Path rule** (`AttachmentDir`, each `AllowedFolders` entry), first match wins:
1. null or whitespace → `Must not be empty.`
2. starts with `\\` or `//` → `Network and device paths are not allowed.`
   (covers UNC, `\\?\` and `\\.\`; this is stricter than, and consistent
   with, `PathPolicy` §12)
3. `!Path.IsPathFullyQualified(value)` → `Must be a full path, like C:\Users\you\Documents.`

**Valid address** (also used by `AddOrEnableSharedMailbox`), on the
trimmed value: length 3–254, exactly one `@`, non-empty part before and
after it, and no whitespace, control characters or any of `<>;,"()[]\`.
No dot is required in the domain.

### `EffectiveAllowedFolders()`

Returns `AttachmentDir` followed by each `AllowedFolders` entry, skipping
null/whitespace entries and skipping any entry equal to one already
returned. Compare with `Path.TrimEndingDirectorySeparator(x.Trim())` and
`StringComparison.OrdinalIgnoreCase`. Return the trimmed values (without
the trailing-separator trim). If `AttachmentDir` is null or whitespace, it
is left out. It doesn't call `GetFullPath`, because `PathPolicy` does that.

### Shared mailbox helpers (§6.2)

- `FindSharedMailbox(smtp)`: compare `entry.Smtp?.Trim()` with
  `smtp.Trim()`, OrdinalIgnoreCase. Skip null entries. If several match,
  return the first.
- `AddOrEnableSharedMailbox(smtp, displayName)`:
  - If the trimmed `smtp` isn't a valid address, throw
    `ArgumentException($"'{smtp}' is not a valid email address.", nameof(smtp))`.
  - If an entry exists, set `Enabled = true`. If `displayName` is not blank,
    set `DisplayName = displayName.Trim()`. Leave `IndexedFolders`,
    `RetentionMonths` and `Smtp` alone. Return that entry.
  - Otherwise append `new SharedMailbox { Smtp = smtp.Trim().ToLowerInvariant(), DisplayName = displayName?.Trim() ?? "" }`
    (default folders, `Enabled = true`, `RetentionMonths = null`) and return it.
- `DisableSharedMailbox(smtp)`: set `Enabled = false` on the match and
  return true, or return false. Never remove the entry. (§6.2: "The mailbox
  is disabled either way". Deleting the index file is `MailboxIndexes`'
  job.)
- `SharedMailbox.MenuLabel`: blank `DisplayName` → `Smtp`, otherwise
  `$"{DisplayName} <{Smtp}>"`.
- `SharedMailbox.EffectiveRetentionMonths(g)` → `RetentionMonths ?? g`.

### JSON (`settings.json`, §5.1)

One static `JsonSerializerOptions` instance, reused:
`WriteIndented = true`, `PropertyNameCaseInsensitive = true`,
`ReadCommentHandling = JsonCommentHandling.Skip`,
`AllowTrailingCommas = true`, and `new JsonStringEnumConverter()` (so
`MeetingInviteMode` and `LogLevel` are written as names, e.g.
`"Send"`, `"Information"`).

- `ToJson()` writes every property with its §5.2 PascalCase name, including
  `SharedMailboxes` entries with `Smtp`, `DisplayName`, `Enabled`,
  `IndexedFolders`, `RetentionMonths` (`null` when unset). `MenuLabel` is
  not written. There is no token property of any kind.
- `FromJson(json)`:
  - Properties missing from the JSON keep their defaults (via the
    parameterless constructors). Unknown properties are ignored.
  - JSON `null` for a whole document → returns `new Settings()`.
  - After deserializing, any `null` string or list property on `Settings`
    is replaced by its default (`TimeZoneLabel` → `""`, `AttachmentDir` →
    the default path, `IndexedFolders` → default folders,
    `AllowedFolders` → the default list, `SharedMailboxes` → empty). On each
    non-null `SharedMailbox`, `null` `Smtp`/`DisplayName` → `""` and `null`
    `IndexedFolders` → default folders. `null` **entries** inside lists are
    kept, so `Validate()` reports them.
  - It doesn't call `Validate()`. Invalid values are kept, and the caller
    (M4.2) decides what to do.
  - Malformed JSON or an unknown enum name throws `JsonException`. Don't
    wrap it.
- `Clone()` is a deep copy: new lists, new `SharedMailbox` objects, same
  values. A JSON round trip is acceptable.

## Spec changes (proposed)

Add to SPEC §5.2, directly after the `Settings.Validate()` paragraph:

> Bounds not given in the table: `Port` 1024–65535; `WorkStartHour` 0–23,
> `WorkEndHour` 1–24 and later than the start; `TimeZoneLabel` empty or at
> most 16 printable characters; `IndexedFolders` needs at least one
> folder, without duplicates. `AttachmentDir` and every `AllowedFolders`
> entry must be a fully qualified local path (no UNC or device paths). An
> empty `AllowedFolders` list is valid. `SharedMailboxes` entries need a
> valid, unique `Smtp`. `Validate()` returns every error as (field,
> message) and never throws.
>
> `IndexedFolders` entries are folder paths relative to the mailbox root,
> `\`-separated (e.g. `Inbox\Projects`). `Inbox` and `Sent Items` always
> mean the mailbox's default Inbox and Sent Items folders, whatever
> Outlook's display language.
>
> `settings.json` uses the names in this table (PascalCase), with enums as
> names. Missing or `null` values take their defaults, and unknown
> properties are ignored. The model and its JSON shape live in Core
> (`Settings`). `SettingsStore` only reads and writes the file.

Add to SPEC §18 "Decided":

> - Settings (M1.7): `MeetingInviteMode` is its own Core file, shared by
>   `Settings` and `InviteGate`. Unchecking a shared mailbox sets
>   `Enabled = false` and keeps the entry, so its folders and retention
>   survive re-checking it.
