# M12.1 Core update primitives

Base: `dev` after the M11 review (ef4d7e8 or later). Core only, plus one
line in each of two existing Core files and their tests. No App changes,
no csproj changes. M12.2 and M12.3 build on these types in parallel, so
**the names and signatures below are fixed**. Don't rename them.

## Goal

Add the pure, Linux-testable building blocks of auto-update (SPEC §20.2–§20.8,
§20.10, §6.7, §5.2, §6.4, §7). They cover versions and SemVer
precedence; the pinned GitHub endpoints and the redirect host
allow-list; release JSON parsing; `SHA256SUMS.txt` parsing; file
hashing; install paths and the installed-copy check; due-time policy;
the `update-state.json` model and store; all update texts; and the
About window's view model. Also add the `Updates` setting,
`ActivityKind.Update`, `ActivityHub.IsActive`, and the four update
balloon texts. Nothing here does network I/O, starts processes, or
renames the exe.

## Hard rules that apply here

- **No Graph, no OAuth, no telemetry.** The only URLs are the
  `UpdateEndpoints` constants below. No literal containing
  `api.github.com`, `githubusercontent.com` or `/releases/download/` may
  appear in any other file under `src/`. M12.4 adds a scan for this.
- Nothing here touches Outlook, mail, the token or Claude credentials.
  File operations are limited to `update-state.json` and its `.tmp`
  file.
- Don't add `Process.Start`, `HttpClient` or `.Kill(` anywhere.

### `SemVersion.cs`

```csharp
namespace ClippysRevenge.Core;

/// <summary>SemVer 2.0.0 version (SPEC 20.2). Build metadata is accepted by TryParse and dropped.</summary>
public sealed class SemVersion : IComparable<SemVersion>, IEquatable<SemVersion>
{
    public const int MaxLength = 256;
    public static SemVersion Zero { get; }                       // 0.0.0
    public int Major { get; }
    public int Minor { get; }
    public int Patch { get; }
    /// <summary>Dot-separated pre-release identifiers; empty for a full release.</summary>
    public IReadOnlyList<string> PreRelease { get; }
    public bool IsPreRelease { get; }

    /// <summary>Strict SemVer 2.0.0 (no trimming, no leading "v"). False for null, blank, longer than MaxLength,
    /// leading zeros in numeric parts, or numbers that don't fit an int (major/minor/patch).</summary>
    public static bool TryParse(string? text, [NotNullWhen(true)] out SemVersion? version);

    /// <exception cref="FormatException">text isn't a valid SemVer.</exception>
    public static SemVersion Parse(string text);

    /// <summary>Only "v&lt;MAJOR&gt;.&lt;MINOR&gt;.&lt;PATCH&gt;" with no pre-release and no build part, each part
    /// 0 or 1–9 digits without a leading zero (regex ^v(0|[1-9]\d{0,8})\.(0|[1-9]\d{0,8})\.(0|[1-9]\d{0,8})$).</summary>
    public static bool TryParseReleaseTag(string? tag, [NotNullWhen(true)] out SemVersion? version);

    /// <summary>SemVer 2.0.0 §11 precedence. null sorts before every version.</summary>
    public int CompareTo(SemVersion? other);
    public bool Equals(SemVersion? other);                       // CompareTo == 0
    public override bool Equals(object? obj);
    public override int GetHashCode();                           // consistent with Equals
    /// <summary>"1.2.3" or "1.2.3-beta.1" (never a leading "v", never build metadata).</summary>
    public override string ToString();

    public static bool operator ==(SemVersion? a, SemVersion? b);
    public static bool operator !=(SemVersion? a, SemVersion? b);
    public static bool operator <(SemVersion? a, SemVersion? b);
    public static bool operator >(SemVersion? a, SemVersion? b);
    public static bool operator <=(SemVersion? a, SemVersion? b);
    public static bool operator >=(SemVersion? a, SemVersion? b);
}

/// <summary>The running build: version + optional commit (SPEC 20.2).</summary>
/// <param name="Commit">Lower-case hex, 7–40 chars, or null.</param>
public sealed record AppVersionInfo(SemVersion Version, string? Commit)
{
    public static AppVersionInfo Unknown { get; }                // (SemVersion.Zero, null)
    /// <summary>First 7 chars of Commit, or null.</summary>
    public string? ShortCommit { get; }
    /// <summary>"0.0.6+ce8976…" → (0.0.6, "ce8976…"). Never throws.</summary>
    public static AppVersionInfo Parse(string? informationalVersion);
    /// <summary>AssemblyInformationalVersionAttribute, else AssemblyName.Version as major.minor.build. Never throws.</summary>
    public static AppVersionInfo FromAssembly(Assembly? assembly);
}
```

## Behavior

### A. `SemVersion` and `AppVersionInfo`

- `TryParse` uses the official SemVer 2.0.0 grammar:
  `^(0|[1-9]\d*)\.(0|[1-9]\d*)\.(0|[1-9]\d*)(?:-((?:0|[1-9]\d*|\d*[a-zA-Z-][0-9a-zA-Z-]*)(?:\.(?:0|[1-9]\d*|\d*[a-zA-Z-][0-9a-zA-Z-]*))*))?(?:\+([0-9a-zA-Z-]+(?:\.[0-9a-zA-Z-]+)*))?$`
  with `RegexOptions.CultureInvariant` and a 100 ms match timeout
  (timeout → false). Major, minor and patch must pass
  `int.TryParse(…, NumberStyles.None, InvariantCulture)`. Pre-release
  identifiers are kept as strings. Build metadata is dropped.
- Precedence (SemVer §11): compare major, minor, patch numerically. Then
  a version without pre-release is greater than one with. Otherwise
  compare identifiers left to right: two numeric identifiers (all
  digits) compare numerically (compare length first, then ordinal, so
  long digit strings work); numeric < alphanumeric; two alphanumeric
  compare ordinally. If all shared identifiers are equal, the shorter
  list is lower.
- `GetHashCode` combines major, minor, patch and the pre-release
  identifiers (ordinal).
- `AppVersionInfo.Parse(s)`: null/blank → `Unknown`. Trim. Split at the
  first `+`. The left part through `SemVersion.TryParse`, else
  `SemVersion.Zero`. The right part is the commit only when it matches
  `^[0-9a-fA-F]{7,40}$`; it is stored lower-case. `ShortCommit` is the
  first 7 chars.
- `FromAssembly(a)`: null → `Unknown`. The
  `AssemblyInformationalVersionAttribute` when present and not blank →
  `Parse`. Else `a.GetName().Version` → `"<Major>.<Minor>.<Build>"` with
  a negative `Build` read as 0 → `Parse`. Else `Unknown`. Never throws.

### B. `UpdateRelease.cs`

- `AssetUrl`: validate the tag with `TryParseReleaseTag` and the asset
  name (ordinal) against the two constants, then
  `new Uri("https://github.com/dirkpetersen/clippys-revenge/releases/download/" + tag + "/" + assetName)`.
  Build the base from a private constant in this file.
- `IsAllowedRedirect`: `target.IsAbsoluteUri`, `Scheme == "https"`
  (ordinal, `Uri` lower-cases it), `IsDefaultPort`, `UserInfo` empty,
  `IdnHost` in the list (OrdinalIgnoreCase). Anything else, or null →
  false.
- **`ReleaseParser.Parse(json)`** (SPEC §20.4), first failure wins:
  1. null, or `json.Length > MaxJsonBytes` → `ReasonBadJson`.
  2. `JsonDocument.Parse(json, new JsonDocumentOptions { MaxDepth = 32 })`;
     `JsonException` → `ReasonBadJson`. Root not an object →
     `ReasonBadJson`.
  3. `draft` / `prerelease`: missing → false; `true` → `ReasonNotFullRelease`;
     any other non-bool kind → `ReasonBadJson`.
  4. `tag_name` not a string, or `TryParseReleaseTag` fails →
     `ReasonNotFullRelease`.
  5. `assets` missing or not an array → `ReasonNoAssets`. Take the first
     element (array order) that is an object whose `name` string equals
     `ExeAssetName` (ordinal), and the same for `SumsAssetName`. Either
     missing → `ReasonNoAssets`.
  6. For both: `state` present and not the string `uploaded` →
     `ReasonNoAssets`. `size` must be a JSON number readable with
     `TryGetInt64`. Exe: `MinExeBytes <= size <= MaxExeBytes`. Sums:
     `1 <= size <= MaxSumsBytes`. Otherwise `ReasonNoAssets`.
  7. `published_at`: a string that parses with
     `DateTimeOffset.TryParse(s, InvariantCulture, AssumeUniversal | AdjustToUniversal)`
     → that value; anything else → null.
  8. Exe `digest`: a string matching `^sha256:([0-9a-fA-F]{64})$` → the
     hex, lower-case; else null.
  Every other field is ignored.
- **`Sha256Sums.Find(text, name)`**: null → null. Remove one leading
  U+FEFF. Split on `\n`, drop a trailing `\r` per line. Each line is
  matched against `^\s*([0-9a-fA-F]{64})\s+\*?(.+?)\s*$` (the
  `install.ps1` rule). Collect the lower-cased hash of every line whose
  group 2 equals `name` (ordinal). None → null. More than one distinct
  hash → null. Otherwise that hash.
- `UpdateHash.OfFileAsync`: `FileStream` with `FileShare.Read`,
  `useAsync: true`, buffer 81,920, through `SHA256.HashDataAsync`.

### C. `UpdateState.cs`

1. **`UpdatePaths.Default(lad)`**: exactly as in the XML comment.
   `Path.IsPathFullyQualified(lad)` must be true.
2. **`UpdatePolicy.IsDue(s, now)`**: `lastCheck` and `lastAttempt` are
   the stored values, or null when the stored value is more than
   `FutureTolerance` after `now`. Due when
   `(lastCheck is null || now - lastCheck >= CheckInterval) && (lastAttempt is null || now - lastAttempt >= RetryAfterFailure)`.
3. **`UpdateStateStore.Load` / `TryLoad`** and the sanitizer:
   - The file over `MaxFileBytes` (check `FileInfo.Length` first),
     `IOException`, `UnauthorizedAccessException`, `JsonException`, or a
     JSON `null` → empty state. `Load` logs one Warning:
     `"update-state.json could not be read ({Type}); using an empty update state."`
     (`Type` = exception type name, or `TooLarge`). `TryLoad` returns
     false and doesn't log.
   - JSON options: property names as declared (PascalCase), enums as
     strings (`JsonStringEnumConverter`), unknown properties ignored,
     `WriteIndented = true`,
     `DefaultIgnoreCondition = JsonIgnoreCondition.WhenWritingNull`.
   - Sanitize after reading. Each failing field becomes null on its
     own:
     - `LatestTag`: must pass `TryParseReleaseTag`. When it's dropped,
       `LatestPublishedUtc` is dropped too.
     - `FailedVersion`, `NotifiedVersion`: `SemVersion.TryParse`. The
       value is stored back as `ToString()` (normalized).
     - `Staged`: `Version` must parse, `Sha256` must pass `IsSha256Hex`
       (stored lower-case), and `Size` must be in
       `[MinExeBytes, MaxExeBytes]`. Otherwise the whole `Staged` is
       null.
     - `Pending`: both versions must parse, else null.
     - `Notice`: `Kind` defined and both versions parse, else null.
     - `LastError`: remove control characters, trim, cut to 300 chars,
       and blank becomes null.
   - `Save` runs the same sanitizer on a clone before writing, so an
     invalid value is never written.
4. **`UpdateStateStore.Update`** holds a private `Lock` for Load, change
   and Save. It's in-process only. Cross-process use is limited to the
   handover (M12.3), where one side only reads.

### D. Texts and `AboutView.Build`

- All numbers and dates use `CultureInfo.InvariantCulture`. Local times
  are `TimeZoneInfo.ConvertTime(utc, zone)`.
- `ModeLine`, `UpdateModeLabel` and `IsActive` throw
  `ArgumentOutOfRangeException` for undefined enum values.
- **Balloons** (exact; `v` given without "v"):
  - `UpdateAvailable("0.0.6")` → `It looks like there's a newer me: v0.0.6. Right-click me and pick About Clippy's Revenge… to update.`

  - `Updated("0.0.6")` → `It looks like I got an upgrade. I'm now v0.0.6.`
  - `UpdateRolledBack("0.0.6", "0.0.5")` → `It looks like v0.0.6 didn't start, so I went back to v0.0.5. I won't install v0.0.6 again.`
- **`AboutView.Build(s, fw, os, now, zone)`**:
  - `latest` = `TryParseReleaseTag(s.LatestTag)` or null.
  - `Title` = `UpdateTexts.Title`, `ProductName` = `UpdateTexts.ProductName`.
  - `VersionLine` = `VersionLine(s.Running)`. `RuntimeLine` = `RuntimeLine(fw, os)`.
  - `LocationLine` = `s.Installed ? InstalledIn(s.RunningDir) : RunningFrom(s.RunningDir)`.
  - `ModeLine` = `ModeLine(s.Mode)`.
  - `LastCheckLine` = `LastCheckNever` or `LastCheck(s.LastCheckUtc, now, zone)`.
  - `StatusLine`: the first that applies:
    1. `Activity` is `Checking` → `Checking`. `Downloading` →
       `Downloading(s.ActivityVersion ?? "?", s.Percent)`. `Verifying` →
       `Verifying`. `WaitingForIdle` → `WaitingForIdle`. `Installing` →
       `Installing(s.ActivityVersion ?? "?")`.
    2. `ActionMessage` not null → it.
    3. `LastError` not null → `CheckFailed(LastError)`.
    4. `latest` null → `NoCheckYet`.
    5. `latest <= s.Running.Version` → `UpToDate`.
    6. `latest.ToString() == s.FailedVersion` →
       `FailedBefore(latest, s.Running.Version)`.
    7. `!s.Installed` → `AvailableNotInstalled(latest)`.
    8. `s.StagedVersion == latest.ToString()` → `Ready(latest)`.
    9. `Available(latest, s.LatestPublishedUtc, zone)`.
  - `UpdateNowEnabled` = `s.Installed && s.Activity == None && latest != null && UpdatePolicy.IsNewer(latest, s.Running.Version)`.
  - `UpdateNowText` = `latest != null && IsNewer(latest, running)` ? `UpdateTo(latest)` : `UpdateNow`.
  - `CheckEnabled` = `s.Activity == None`.
  - `DocsUrl` = `UpdateEndpoints.DocsUrl`. `NotesUrl` =

## Spec changes

Already made in `SPEC.md` with this brief (M12 architect commit): §1.11,
§2, §3, §5.1, §5.2 (`Updates`), §6.2, §6.3, §6.4 (`Update` kind), §6.5,

Decisions recorded here that the spec states only implicitly:

1. Release tags for auto-update are `v<MAJOR>.<MINOR>.<PATCH>` with each
   part at most 9 digits.
2. `published_at` and `digest` are optional. A bad `published_at`
   counts as missing, not as an error.
3. `update-state.json` is capped at 64 KiB, and an unknown enum name
   makes the whole file load empty (the standard `JsonException` path).
   That's harmless: the worst case is one extra check.
